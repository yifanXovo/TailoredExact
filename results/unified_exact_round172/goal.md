## C. 统一论文论点，准确呈现现有数学结果

### C1. 三层贡献及其关系

论文围绕同一物理问题建立三个相互衔接的贡献层：

1. **完整精确方法。**共享库存/服务/产品表示、有效物理关系、付费完整初始解与保持全域覆盖的求解流程共同产生可行解和有效下界；计算比较针对完整方法。
2. **表示与条件信息的结构认识。**相同物理投影或相同根松弛不保证保留相同的条件编码信息；局部更紧凑或条件更强不必降低完整求解成本。理论、离线表示研究和完整方法试验分别支持各自层面的判断。
3. **有界的交通决策解释。**用已验证的上下界分析路线时限和连续目标权重的影响，说明哪些决策改善已被界定，哪些仍不可判定。

主文应明确默认 B 实际使用什么。紧凑支撑表示和条件 DAG 属于已有研究结果，不能经改写变成默认 B 中已经启用的优化。GI-TBC 名称保持可识别；标题可按真实中心论点调整，不强制改名，也不暗示区间分裂已被证实是全部性能收益的来源。

原模型、假设和符号一次定义清楚：`F=G+lambda*P`，`P=sum_i omega_i*abs(Y_i/D_i-1)`，仓库不进入公平/目标惩罚，零总库存的 Gini 约定沿既有定义。保持空车出发、整数最终库存、每站至多一次非零单向服务、每个 prefix 的容量、载货回场及卸载时间。区分物理路线时限 T 与计算 process cap。

### C2. 共享接口紧凑表示：保留成立条件

以语义名称引入库存/处理量/服务指示/产品的联合状态接口。历史 C166、D167、R_abs、LOG 等标识只在一次实现对应表或补充材料中说明；代码、原始结果和历史方法名称不全局改名。

对于连续整数域 `D=[l,u]∩Z`、初始库存 b 和 `g∈[alpha,beta]`，沿现有证明说明联合局部对象：

`conv{(y, |b-y|, 1[y!=b], g, g*y): y in D, alpha<=g<=beta}`。

至多五个支撑位置来自 `{l,u} ∪ ({b-1,b,b+1}∩D)`。这里的紧凑结果须与“其它被删除状态的用途全部经同一接口表达”的条件一起出现。相应整数精确性还需要既有的绝对库存二进制产品层；不能只凭连续支撑权重加 integer Y 宣称乘积精确，也不能将支撑权重改成选择一个支撑点而删去中间整数库存。

保留已知边界：独立 state/product 块本身与相应 McCormick 投影的关系；原 target penalty 仍按既有 epigraph 表达，不能未经证明将新的精确状态函数视为已覆盖；额外阈值、精确状态惩罚、车辆状态指派或有孔整数域需要相应接口/域表达。把证明与一般背景凸化技术区分开，不将标准工具包装为新的普适凸化定理。

### C3. 条件编码信息：呈现可推广对象，不扩大条件

准确保留 R167 已证的对象：相同绝对二进制编码的库存、服务、处理量、产品与 code 联合图；连续整数域中的 `m(y)=|b-y|`、`v(y)=1[y!=b]` 按 donor/initial/receiver 至多三段构造；在该绝对编码的部分位被固定后，双流 DAG 保留相应条件凸包。基本流 f 与乘积流 q 在同一边上，满足 `Af=e`、`Aq=g*e` 及 `alpha*f<=q<=beta*f`，其中 e 为单位源汇需求向量。其局部规模写作 `O(1+log(C+1))`。不在本轮将任意“有限分段函数”默认为已证推广；如确需提及更一般共同分段仿射函数，只能引用已有明确证明并同时给出假设及段数依赖。

保留现有具体反例，使“相同物理投影不保留相同条件信息”可被直接理解。例如现有 `D={0,...,4}`、`b=2`、`g∈[0,.5]`、最低位固定为1，只剩库存1与3；联合图中处理量和服务指示均为1，而分离后的接口混合可能在 Y=2 给出零处理/零服务。按现有证明给出完整一致数值及为何非法，不凭印象改写反例。

这不是任意 Native 分支下的全路由凸包，也不是已证明的搜索树普遍优势。绝对 bit 编码不能与历史带 offset 的 LOG 编码混写。network/disjunctive 方法的既有出处继续正确引用；只针对实际改变的理论表述核对必要原始来源，不扩展为新文献普查或硬性要求发现新定理。

完整证明继续留在当前数学附录。可改善命题编号、定义顺序、短证明解释与交叉引用，但不为了主文字数删除假设或证明可达性。

## D. 重写 Algorithm 1 的表达，保持实际算法

本节是文稿的实质修订，不修改求解代码。先给研究者可理解的数学状态：已物理验证的 incumbent U、仍需覆盖的 Gini 域、带适用范围的区域下界、与 incumbent/模型状态有关的版本，以及 cutoff 的互补覆盖。再用清楚的数学操作表达算法；实现函数名、字段和 exact-continuation 对照放入 Appendix B。

以实际冻结实现和 Appendix B 为准，以下含义必须保留：

1. **初始可行解与改善域。**完整 own H 与物理验证计入共同 deadline；H 仅提供 U，不自动提供正下界。覆盖 `[0,min(U,(n-1)/n)]` 的全部潜在改善 Gini 域，含零边界；独立的全域非负下界始终有效。
2. **选择与适用性。**保持 minimum-bound plateau 内既有 widest-first cycling；每个 bound 只用于其真实区间、模型/状态版本及 cutoff 所允许的域。外层 NEXT 的非控制叶重排和下一严格较高 open floor 的目标继续准确表达。
3. **双子区间与原子替换。**两个 child LP 都完成并有合格返回后，才按现有规则决定是否原子替换 parent。AM 按既有公式使用 raw child LP bounds、own U 和父 floor，不能用继承下界取 max 后的数值替代 raw child bounds。保持不可行区域的逻辑、有限双侧 AM 判定及 `.08` 门槛；不把尚无返回的 child 当成已覆盖。
4. **未接受分裂仍有精确续解。**存在严格有效 child-minimum 提升时，按现有流程对原 parent 域运行带目标的 MIP；没有这种提升或触发深度8/宽度`1e-4` guard 时，仍保留完整 parent MIP 的 exact continuation。深度或宽度阈值不能作为已证明区域结束的理由。
5. **目标不是证据。**requested target 只是停止目标，必须使用实际返回的合格 Native bound；不能将“要求达到”写成“已经达到”。只有 NEXT 目标被实际达到并按返回规则确认时，才设置其里程碑；child-target 不设置该里程碑，也不强制随后分裂。若仍未解决，parent requeue 及其义务保留。
6. **新 U 与有效证据。**Native 返回中的可行 fleet 经原目标和物理检验后更新 U。U 改善后按原规则失效 model/LP/child 缓存，仍适用的旧 cutoff 下合格 floor 继续保留；NEXT 里程碑不因 epoch 递增而重置。与旧 U/模型版本关联的区间、cutoff 和 source 只在仍适用时使用；不能通过换 incumbent 丢失未解决区域。
7. **下界合成。**同一域上可适用的独立下界取最大；完整 cover 及其 cutoff complements 之间取最小。保留取得证据时 cutoff 所排除部分的证明义务。证明记账使用 `min(L_source, cutoff_source)` 与相应补集；冻结代码并不普遍将 raw bound 截到 U，文稿须区分理论域记账和实际数值记录。
8. **失败、timeout 与 OPEN。**未解决义务不能在到时后消失。资格拒绝沿实际已有保守恢复规则保留原物理域与独立 floor。区分论文的资格规则、实际运行代码与事后审计；不要给冻结 B 虚构尚未实现的通用在线依赖撤销系统。
