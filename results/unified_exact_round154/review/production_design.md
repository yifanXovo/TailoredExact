## Same producer, different consumer

E uses the exact existing R153 online Python producer, dependency closure,
NodeLimit4096, zero relative MIP gap and original price absolute target1e-4.
Its helper is still called once after the run's own H against the current
canonical source, with a whole-method remaining deadline and owned hidden
job. No offline stock, potential, bound or another arm's H is loaded.
The new build helper requires its dependency map to equal the R153 map.

The existing R153 control gains proof_only, default false, preserved on
reset. In the embed function, E skips only the floor-row append condition.
All source/input/coefficient/resource/support/Gini/cutoff and descendant
checks remain in the old code. J sets proof_only false and retains the
old row behavior; B disables the producer. E returns the unmodified base
artifact, including objective, cutoff, variables, types and rows. The old
Native actual-row audit receives an empty expected floor-row set and still
checks actual Native absence. Recompiling the affected translation units
therefore preserves a matched B/E/J PE without changing the floor producer.

The CLI exposes an explicit off/on proof-placement flag; the campaign
pairs E with root-floor on and keeps it off for B/J. Existing isolated
stable-GI-TBC checks guard the enabled root-floor path. No role, size,
historical-winner or elapsed-time component switch was introduced.

## Complete root and scoped proof composition

After embed, E binds complete_root to all of:

- L0 with no parent and exactly one initial interval;
- the actual base and saved producer Gini endpoints equal to the complete
  controller root endpoints;
- producer source SHA equal to that actual original root base artifact.

This is stronger than treating the first artifact or c.generated as
global evidence. The same actual source already binds current own cutoff,
input, ratios, objective weights, supports and resources. The old
descendant scope checks remain, while a ledger leaf outside source Gini
coverage or with a larger cutoff gets no floor.

round154ProofLedger makes a value copy of the existing
ControllingLeafScheduler. It changes only the copy, through its existing
mergeValidLowerBound interface. For each covered nonreplaced/noncoalesced
leaf it merges min(U0,ell). The scheduler's own final-leaf aggregation
then gives the required min_j max(raw_j,covered_floor_j).
Uncovered leaves retain raw bounds, and old closed/replaced/coverage
semantics remain. The cutoff complement is paid explicitly; it is not
an unconditional use of a local ell above a source cutoff.

The copy includes value-semantic vectors, histories and leaf records; it
does not alias the original scheduler's leaf state. The original scheduler
still supplies all selection, parent/child bound, AM, target normalization
and search ordering expressions. No constant is substituted into AM parent
and child gains. Only a separately composed proof closure may stop the
whole algorithm before the next search step.

The two early closure checks now pass the actual source-live condition
!native_evidence || native_evidence->proofUsable(). They require both
everyRelevantLeafClosed() and proof global lower within the old tolerance
of the verified physical U. The scheduler already treats an open-status
leaf with a qualified lower excluding its cutoff as discharged; no
fabricated Native OPTIMAL status is needed. Ordinary finalization releases
the backend and retains the established lifecycle/physical/certificate
gates.

## Final proof identity and revoked sources

The final copy is composed only after the existing native-source
revocation handling. A revoked source abandons old bound/closure state,
restores the old complete-domain open fallback, and disables the new
floor in final proof composition. Existing hard-failure/open policy is
retained.

The final paper_leaf_ledger.csv uses the proof-copy lowers and provenance;
round154_proof_ledger.json separately saves every raw search lower, proof
lower, scope/cutoff, root/source identity, global values and stopping flag.
This avoids reporting an externally raised global L while leaving an
inconsistent leaf ledger. Result/global L, all-relevant-closed and
certificate input read the same final proof copy.

The final trace receives the proof lower only at finalization, while all
earlier call/journal/AM records retain their original search bounds.
The result's strict_lower_bound_source now explicitly describes the
per-frontier max with cutoff-complement own-root floor when that source
is accepted, complete and live. It no longer mislabels the new proof as
solely Native/LP evidence.

B and J call the new copy helper but it is inactive for them, so their
final controller and search inputs stay on their old paths. Extra
default-off branch checks can add ordinary overhead; no bitwise timing
equivalence is promised.

## Narrow independent reader adaptation

The adapter reuses the entire old floor/source contract and changes its
expected appended-row count to zero only for E. It still checks original
rows/columns/types/bounds/objective, actual Native row audits, own source
scope, actual helper price lower, true returned stock values and source
identity. Thus its same-domain Native equivalence to B is a checked
matrix-identity argument from E's own original base, not yet a claim that
a new B arm's result was observed.

The added control audit binds the final proof ledger to the own source,
cutoff complement, root Gini scope and single initial root. It verifies
every recorded leaf proof lower against max(raw,floor) only when covered/
accepted/live, verifies floor provenance, recomputes relevant-leaf minima
and matches published result L. An absent source now requires false
qualified/complete flags, proof==raw on each leaf/global and no floor
provenance, retaining the old safe B information.

Only the final complete-cover function's accepted-source set and scoped
proof collector are extended, process-locally. The added proof has the
audited root interval, min(U0,ell), source cutoff, source/model and audit
SHA. Existing supported_leaf_bound partitions still verify the entire
true-G cover, including cutoff complements. No unconditional replacement
of final L or omission of uncovered leaves is made.

The chronological native-call cover remains the original function with
the original raw sources; no future floor is backdated into an earlier
native bound or AM event. The external proof has no Native call/sequence
and is admitted only by the final complete-cover collector. This
separation is appropriate: changing chronological_cover's global proof
collector without special event handling would have made call=None
invalid or invented a chronology.

The old physical route replay, own-H reconstruction/neutral exchange,
Start mapping, model domain, native quality, rejection, returned-call
and release/lifecycle checks remain in the invoked reader chain.
A PASS still requires them; the new floor does not bypass a native
contradiction or make a failed producer ordinary open performance evidence.

## Actual issues identified and repaired in this source review

1. Early proof checks initially used the ledger helper's default
   sources_live=true. Both now pass actual native proof usability.
   Final revocation already disabled the floor; the repair also avoids
   claiming proof-triggered early stopping on a revoked source.
2. Final strict_lower_bound_source initially described only the old
   Native/LP bound family. It now labels the actual external-frontier
   composition.
3. A final proof ledger can exist before any canonical source is
   materialized. The initial adapter required nonnull source metadata
   whenever a ledger existed. It now explicitly accepts only an unchanged
   raw proof ledger in that unavailable-source path and retains B
   information.

These were targeted new-consumer issues, not reasons to reopen old helper
process/dependency qualification. Their exact later source bytes below
were reread.
