# R95 full two-station block: fixed-witness G2 result

The one authorized G2 batch ran D6, E8, then S12 from the frozen R95 preregistration. All three isolated diagnostics exited normally, exhausted their complete pair domains before the 120-second case and 360-second shared limits, and found **no strict improvement in original F**. This is a negative result for these three fixed R88 physical witnesses: D6 is the old startup final closure route; E8 is the first verified startup witness before two equal-F neutral relocations, so it is not asserted to be the later closure route; S12 is the first verified startup witness, with zero old neutral moves. It does not measure a production R76/R83 integration or a new ENS run. The positive G1 result remains the hand-derived microexample in which the full block improves a verified R76/R83/R93 stop; see [g1_identity_manifest.json](g1_identity_manifest.json) and [g1_independent_review.md](g1_independent_review.md).
