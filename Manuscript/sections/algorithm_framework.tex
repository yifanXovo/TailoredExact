\section{Tailored Gini-Interval Branch-and-Cut Framework}
Suppose an independently verified incumbent has objective $\cutoff$. Since
$P\geq0$, every improving solution has $G<\cutoff$. K1--AM--SF begins with one
closed interval ($K_0=1$) covering the complete improving Gini domain. It
maintains a ledger of closed intervals $\Gamma_q=[\gamma_q^L,\gamma_q^U]$
whose union covers that domain. Unresolved leaves are refined at their exact
midpoints using the adaptive-mass score and the frozen threshold
$\tau=0.08$. Native-target handling, exact-parent closure, and
child-infeasibility handling are inherited unchanged from the qualified
controller.

For each leaf, the sparse tailored fixed-interval MILP solved by Gurobi's
native branch-and-cut enforces
\begin{align}
 \gamma_q^L &\leq G\leq\gamma_q^U,\label{eq:ginterval}\\
 G+\lambda P &\leq \cutoff-\eps.\label{eq:cutoff}
\end{align}
It is the F0--CLEAN formulation: the Round 50 v0 model with only the
historical exhaustive $V\leq12$ subset-duration block removed. A timeout or
wrapper checkpoint never closes a leaf by itself.

\begin{proposition}[Fixed-interval no-improver validity]
If the original compact model together with \eqref{eq:ginterval},
\eqref{eq:cutoff}, and valid static strengthening is infeasible, then no
original feasible solution in $\Gamma_q$ improves the incumbent.
\end{proposition}
\begin{proof}
Every original improving solution in $\Gamma_q$ satisfies the original model,
the interval and cutoff rows, and every valid strengthening row. Such a
solution would contradict infeasibility.
\end{proof}

\begin{theorem}[Global exactness]
Let $\widehat x$ be independently verified with objective $\cutoff$. If the
final leaves exactly cover every improving Gini value, every leaf is closed by
a scope-valid bound, exact fixed-interval infeasibility, valid fixed-interval
best bound, or empty-domain proof, and no invalid or open leaf remains, then
$\widehat x$ is globally optimal.
\end{theorem}
\begin{proof}
Any better solution has a Gini value in one final leaf, whose valid closure
excludes that improving solution, a contradiction.
\end{proof}

Operationally, the framework verifies a same-run incumbent, initializes the
complete K1 ledger, propagates interval domains, solves unresolved leaves with
F0--CLEAN, refines only through the frozen midpoint/adaptive-mass rule, merges
only scope-valid evidence, and certifies only after coverage and independent
solution audits pass. The stable algorithm registers no dynamic user-cut
callback.
