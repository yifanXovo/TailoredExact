This also exposes an existing capability gap: running original R83 on late
native witnesses already improves D7 and F5 and U6-early. The new gain must be
measured after that baseline, not attributed to new order code wholesale.
The new descent interleaves same-route order moves with old intervehicle moves
and original quantity/insertion closure; it is not pure fixed-owner reordering.
F5's separate free-order MILP returned its start at the 300 s cap, bound
.0811925861, and therefore did not settle whether order alone suffices.

Independent replay checks all persisted physical witnesses and all 85 new
neutral moves. Each preserves inventory, ownership and operations and strictly
decreases the exact duration tuple recomputed from the C++ distance snapshot.
The first offline analyzer invocation encountered the C++ triple-array operation
schema; it was corrected before producing an audit, with no optimization rerun.

Freeze this single default-off integration: `--round96-route-order true` replaces
the one existing R83 startup closure call on the best candidate after the
unchanged 24+1 startup. The replacement itself first runs exactly R83 and then
the qualified order/old-closure alternation. It is not applied separately to all
25 seeds, native incumbents, nodes, or timed slices. Default false preserves the
old call. Reject combinations with A1, native B1, LP-G, H-ACT and other candidate
channels. Original model, Gini tree, split geometry and numeric settings stay
unchanged. Record a distinct effective algorithm identity and complete trace.

This location is a deliberately limited first end-to-end test: late-native
snapshot benefits do not prove that startup-only use improves a complete solve.
The predeclared F5/F2 OFF/ON/P comparison and two untouched validation roles
remain mandatory before a primal adoption claim. D7 diagnostic F is below the
old offline P witness, but no certificate or production performance win follows.
F5's new diagnostic F is still above the old P witness .2999915385.

Third-perspective self-review (not an independent agent): physical and finite
descent qualifications pass; real quality gain exists at modest measured cost;
the two U6 negatives and the failed-to-resolve MILP contrast are retained.
Admit isolated end-to-end research, not default promotion or LP-G combination.
