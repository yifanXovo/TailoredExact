# MB-PC mathematical and handoff contract

The original physical problem and evaluator in R118 `paper_algorithm_spec.md` remain unchanged: Y=b+sum(d-p), integer one-way unique service, 0<=Y<=C, empty departure, every prefix and return load in [0,Q], loaded return with paid unloading, duration travel+(pickup_seconds+drop_seconds)*total_pickup. Q is simultaneous load, and min_ratio is not a new inventory floor. F=G_true+lambda*sum(w_i*abs(Y_i/D_i-1)), using the original zero-ratio-sum Gini convention.

A returned certificate C records interval I=[a,b], original immutable model SHA/path/scope, complete original-problem embedding, original non-strict cutoff c, returned call/status, numerical lower bound ell, epoch and dependencies. It asserts only: physical original feasible points with G_true in I and F<=c satisfy F>=ell. A qualified infeasible return can instead use the cutoff boundary c for the complement argument; UNKNOWN, feasible objective, local node value, unreturned callback and a last printed value do not establish C.

## Cutoff complement and inheritance

Every physical point in I either has F<=c and hence F>=ell, or has F>c. Therefore b_I=min(ell,c) is a conservative lower bound over the complete physical interval. With the unchanged tau=1e-7 evidence contract, only a verified own U satisfying U+tau<b_I permits exclusion from the strict improvement domain. Equality, tolerance margins, unspecified cutoff semantics or uncertain endpoints do not trigger.

Counterexample: a restricted F<=.5 problem may have bound 1 (including an empty restricted set), while a physical point outside that cutoff has F=.6. Using 1 to exclude under U=.7 is invalid; min(1,.5)=.5 correctly does not exclude. Separately, the lower bound 1 for min x on [1,2] cannot be inherited by [0,2], whose optimum is 0. Restriction inherits containing-domain evidence, never the reverse or across siblings.

For U<=c, every F<U point is in the original cutoff. Any new true-G subset of I inherits C, provided the original embedding/F0/domain premises remain valid. The original model epigraph g need not equal true G at a solver point: for the embedding of a physical point we select the legal exact g=G_true and exact product/inventory representation. A rejected old model-g value alone does not exclude the physical fleet. Every candidate remains independently replayed by the original Evaluator; physical G, complete integer Y and deterministic F bind the event.

## Cover, incumbent, and numerical reliability

Each transaction retains the original parent interval as the exact union of the closed retained and removed intervals sharing the actual split endpoint. Removed pieces retain their certificate identity and cutoff-complement proof; they are improvement-fathomed, not asserted physically infeasible. Remaining active obligations, archived removed pieces and the original analytic G/objective tails cover the complete original problem. Global L is the minimum of valid bounds across that cover, with each cutoff complement; the removed side's ell never becomes the other side's or parent's bound. Parent lower bounds may be inherited into narrower children.

A valid own U is preserved even if its backend call is interrupted. A complete cover containing no strict improver establishes original optimality only under the inherited numerical certificate policy. A local INFEASIBLE result alone is not global physical infeasibility. A same-scope physical counterexample invalidates the numerical certificate and every dependent pruning/closure/optimality claim. Legal own fleets do not repair earlier erroneous pruning; such a candidate fails correctness and performance admission (PROOF_RELIABILITY_PRIORITY).

## Finite event and native lifecycle

Only naturally paid and returned midpoint-child evidence is registered; no additional oracle/probe or LP budget is purchased. Applicable proof pairs are considered deterministically by ancestor depth, original tree ID, then left/right order. A proof cannot cause two transactions. A new active leaf has exact parent/child lineage, incremented depth and new scope/generation; original depth8/minimum-width safeguards remain. Finite integer inventory/fleet objectives and strict deterministic own improvement avoid callback noise cycles. Finite tree depth bounds all new domains; an uninformative same-domain restart is rejected by the retained terminal guard.

Before terminal, an already complete eligible proof can transact immediately. During terminal, after physical MIPSOL verification, the callback only saves an eligible event and requests GRBterminate. It does not alter bounds, optimize another model or update the scheduler. The [Gurobi C callback reference](https://docs.gurobi.com/projects/optimizer/en/current/reference/c/callback.html) specifies that GRBterminate requests termination, may take time to be acted upon, and returns the interrupted status when optimization stops. The [C++ callback reference](https://docs.gurobi.com/projects/optimizer/en/current/reference/cpp/callback.html) describes the corresponding abort entrance. Only after a real accepted return and cleanup may the controller atomically update the cover and adopt the new incumbent epoch. Unknown/error returns fail; deadline/resource stops have priority. Old bounds and returns keep the old model and scope.

All work, termination latency, physical checks, journals, model destruction/rebuild, new LP/MIP and complete own Start mapping consume the unchanged absolute producer deadline. No remaining time means no new native call. The new domain enters the original controller/AM. The old B&B tree, local cuts and basis are not promised to migrate. Start comes only from the same-run verified fleet, tested against every actual native row/column/type/bound/objective and the new true-G domain; an unexpected mapping failure is a qualification failure, never an invitation to import historical routes.

This is standard scoped bound pruning/OBBT reasoning applied to the existing BRP representation and evidence lifecycle, not a new general theorem or rational B&B proof. Native chain qualification, finite physical enumeration, disabled-feature model regression and eventual fixed performance evidence are separate obligations and have not yet been claimed complete.

A global own incumbent can belong to another live region. No eligible Start in the retained region is then an ordinary cleared/skipped Start under the existing mapper; it is not a physical infeasibility certificate or a reason to import a route. An unexpected mapping failure for an eligible fleet remains an engineering failure. The improving-point embedding theorem applies to all unknown feasible improving points, not just the current known fleet.
