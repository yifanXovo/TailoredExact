## 代理目标与整数边际弧

全站 `i=1,…,n`（包括未访问站，排除 depot），`D_i>0`、当前库存 `Y`、`S=Σ_iY_i/D_i>0`、`A=Σ_{i<j}|Y_i/D_i−Y_j/D_j|`。先为凸分子 `A` 选一个子梯度（相等比率取成对一致的零符号），再代入商式得到 **Gini 比值函数的局部广义梯度**

`g_i=[S Σ_{j≠i}sign(Y_i/D_i−Y_j/D_j)−A]/(n S²D_i)`。

令 `φ_i(y)=g_i y+λ w_i |y/D_i−1|`，其中 `λ,w_i≥0`，允许库存整数 `0≤y≤C_i`。Gini 比值既非凸函数，又在比率相等处有折点；此 `g` **不是全局凸支持下界**，只定义一次局部代理。网络只对固定路线已访问站设置取、放弧；未访问站的 `φ_i(Y_i)` 是常数，仍参与计算 `g` 与原 F。固定代理目标的增量为 `Σ_i[φ_i(y_i)−φ_i(b_i)]`，`b_i` 是原初库存，**不是**上一轮当前库存。若 `S=0`，保持现有确定性 `no_gradient_at_zero` 终止，不虚构 Gini 导数。

在访问站的取弧上，第 `m=1,…,b_i` 单位费用设为 `φ_i(b_i−m)−φ_i(b_i−m+1)`；放弧上，第 `m=1,…,C_i−b_i` 单位费用为 `φ_i(b_i+m)−φ_i(b_i+m−1)`。每条单位弧容量 1，端点与旧网络相同；同费用的**连续**单位可合并成一条相应容量的平行弧。由于 `φ_i` 凸，两个方向的序列各自非递减，给定取量 `p` 或放量 `d`，存在使用各自最便宜前缀的最优弧流，其费用分别恰为 `φ_i(b_i−p)−φ_i(b_i)` 与 `φ_i(b_i+d)−φ_i(b_i)`。整数 `D_i` 时绝对值折点位于整数库存，任一方向最多两种边际费用（折点不在合法库存范围则仅一种）；一般正有理 `D_i` 落在相邻整数之间时，穿越它的一个单位可能产生中间边际值，至多三个连续费用段。精确有理费用可统一乘最小公分母为整数；不得通过浮点 epsilon 合并真实不同的边际。

## 同点取送取消与完整网络等价

旧网络的源→车辆弧限制总取量 `≤K_k`，访问链的载荷弧限制每一前缀 `0≤load≤Q_k`，每站取弧 `≤b_i`、放弧 `≤C_i−b_i`，末端载货可返库，disposal→source 闭合总流。设一整数循环流在同站同时取 `p>0`、放 `d>0`。两方向先各规范为最低边际前缀；费用为 `φ(b−p)+φ(b+d)−2φ(b)`。令 `c=min(p,d)`，同时取消 `c`：净库存仍为 `b−p+d`；站点前后的车辆载荷完全不变，总取量减少 `c`，库存、前缀、容量和**固定模板下的名义时间**不恶化。网络上相应减少该站两组边际弧、源→该车辆及 disposal→source 各 `c` 单位，其余载荷弧保持；再规范前缀即可。

取消后保持**完整固定路线模板**时旅行不变，因总取量下降，名义时间预算不恶化；若净操作变零而删站，旅行只在精确 metric 情形下保证不增。非 metric 或数值三角边界均须由原 C++ 重新验收，不能从流取消推出原物理可行。凸性给出

`φ(b−p)+φ(b+d)−2φ(b) ≥ φ(b−p+d)−φ(b)`。

可用离散增量单调性证明：取消一对时，去掉最后一个取单位的边际与最后一个放单位的边际之和非负；重复 `c` 次。等价地，四点 `b−p ≤ b−p+d ≤ b ≤ b+d`（`p≥d`）或其对称次序具有相同总和，外侧两点的凸函数和不小于内侧两点的和。线性 `g_i y` 部分在取消中精确抵消。因此任一整数循环流可不增费用投影为**每站仅一方向**的同净库存合法流。

反向，对固定网络域中任一合法整数净操作 `y_i`，置 `p_i=max(b_i−y_i,0)`、`d_i=max(y_i−b_i,0)`，每站用相应前缀边际；源→车辆流为 `Σp_i≤K_k`，链弧流为逐站累计 `Σ(p_i−d_i)∈[0,Q_k]`，终点载荷送 disposal，disposal→source 等于总取量。容量及流守恒均成立，成本**等于** `Σ_i[φ_i(y_i)−φ_i(b_i)]`。前一方向说明所有循环流成本至少是其净操作代理成本；反向说明每个合法净操作都能以等成本实现。故整数最小费用循环流的值**等于**整个既有固定网络域的代理目标最小值，而非仅给下界。残量网络无负环/整数势函数证书仍证明扩展网络最优；须连同全部平行弧容量、费用、原流与规范/取消映射审计，不把证书误称原 F 最优。
