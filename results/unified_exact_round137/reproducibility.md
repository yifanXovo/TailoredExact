## What the pure replay checks

The closed-root checker mounts only the exact published source/helper capsule
and explicit input/progress dependencies. It replays the actual current reader,
physical feasibility/original objective, model/lifecycle/native-claim predicates,
post-preset controls and derived evidence for all 120 positions. It compares the
seven saved derived authorities (plus the M-B control audit), preserving each
original measured clock. It recomputes the four transparent T designs,
shortage floors/effective weights, and saved zero-Optimize default/deletion
structural checks. Budget is recomputed once from fees; H/LP/MIP/Work are nested.

Recorded PE/DLL hashes are explicit attestations in public replay: the native
assets are neither shipped nor opened. Source/evidence replay is not an
independent native performance reproduction or a stronger numerical certificate
policy. No Optimize, compilation, vendor DLL loading, Git/raw fallback or
historical whole-campaign recovery is allowed.

## One owned public check and failure handling

After recovery completes, its actual `public_restore_receipt.json` records the fixed 40-hex science
commit, owned restore root, attempts and transport/semantic clocks; only a passed receipt establishes completion.
Read it from the delivered branch head: this delivery receipt is committed after the fixed scientific commit and is outside that immutable manifest. An already passed root must not be rerun;
R135's accepted recovery must not be repeated. The local preflight is a pure
check against current in-place evidence, separately measured from the one
anonymous fixed-commit HTTPS empty-root recovery.

The current Windows recovery uses installed Python and Windows System32 curl.
Its owned destination must be below `E:/codes/ExactEBRP-work/restore`, with no
reparse links. It has a cumulative 9000s envelope and a semantic replay bounded to 4500s. These limits use the actual 2820.379s local strict preflight, with finite transport/expansion margin for the 1.4 million current members.
Only an actual failed recovery may resume, with `--resume` in that same owned
root and against the same fixed commit. Verified downloaded files are reused;
partial transfers/failure logs remain. A transport/reader repair never reruns a
healthy producer or replaces its original clock.

For a separately authorized reader audit, obtain the fixed commit from the
delivered receipt and choose a fresh reader-owned root. The PowerShell command shape is:

    $round137Recovery = Get-Content -LiteralPath results\unified_exact_round137\public_restore_receipt.json -Raw | ConvertFrom-Json
    & 'D:\msys64\ucrt64\bin\python.exe' -B scripts\round137_public_restore.py --commit $round137Recovery.commit --destination E:\codes\ExactEBRP-work\restore\round137-reader-owned --receipt E:\codes\ExactEBRP-work\temp\round137\reader-audit.json

project root is preserved for inspection; this example is not an instruction
