# Round 88：B1/B2 固定 LP 诊断与独立验收合同

状态：待执行协议；本文未运行求解器，也不把数学有效性等同于性能改进。输入、原始目标、Gurobi 设置、证书容差与正式算法的外部全程计费保持原协议。诊断中的统一整进程截止仅产生 `unknown` 研究记录，不得进入正式算法的内部切换规则。

## 1. 固定原 LP 的身份

先从冻结 ENS-C 的一次真实叶/根状态导出并只读保存**原始** VD-P LP `L0`，禁止为各实验臂重新生成具有不同 cutoff、库存域或 Gini 区间的模型。记录：实例文件 SHA256、场景参数（`T`、`lambda`、装卸时间、车辆容量等）、算法源码/二进制 SHA256、预设、叶 ID 与父 ID、`gamma_L=a`、`gamma_U=b`、完整库存支持及 `D_i`、验证过的 incumbent 与 cutoff、列/行/非零元、LP SHA256、模型指纹、求解器版本/线程/种子/容差、原 LP 状态和原始 primal 与目标。核对 `state_i_y`、`state_g_i_y`、`h_i_j`、`G`、`zprod_i` 的存在及 `Σs=1`、`a s≤q≤b s`、`Σq=G`、Gini 行；不符合时标记“不适用”，不得把 bit-product 或不同叶模型当 VD-P 对照。`a=b` 仅作 B1 诊断。

建议先取 D3/D4/C2/F2 的真实叶 LP 与 D7/U6/F5/F6 的保护状态；实例选择依据固定在诊断前，状态身份完整记录。优先使用已导出的合法固定 LP；历史已知最优值仅用于离线核查，不写入正式运行。

## 2. 同源四臂比较

在同一个 `L0` 的已求 LP primal `x0` 上、对全部 `i<j` 分别计算 B1 与 B2；只追加数值上可靠、真正违背的符号行。创建四份**同源副本**：`L0`、`L0+B1(x0)`、`L0+B2(x0)`、`L0+B1(x0)+B2(x0)`，每臂以相同求解器设置独立求 LP。行生成使用同一个 `x0`，不允许 B2 臂基于先求 B1 的新点取符号；这才可解释 B2 的独立价值和 B1→B2 增量。B2 在全符号族中支配 B1，但各臂仅加入有限的当前点行，不能预设有限行后的界严格排序。若做迭代闭合实验，应作为另列协议，对四臂采用同一确定性规则和完整成本，不以秒数或 Work 触发停止。

每对记录 `h`、均值差、`W1`、B2 右端除以 `b−a` 的值、B1/B2 正确单位下的违背量、两端点各层总质量、`Σs−1`、`Σq−G`、所有 `q−a s`/`b s−q` 的最小余量、区间与支持指纹、符号串、行系数及 LP 点代回残差。B2 未归一化行的原始残差也需保存。记录各臂求解状态、原始目标/下界（只在状态允许时比较）、行列非零元增量、LP 构建/分离/写入/模型读取/求解的 wall 与 Work、内存及异常。行的排序与签名应由 `(叶域, i, j, 支持, α, β)` 确定，防止重复和跨叶误用。

预期验收顺序：先证明确有真实分数解，且导出模型基础行残差满足原有数值标准；再给出严格正的 B1/B2 违背见证；最后看同源 LP 根界/行规模/总成本。没有违背、LP 不收敛或数值不可靠均为有效诊断结果，不能报告成算法加速。根界提高也只说明该固定松弛变强，后续完整 ENS/P-GRB 运行仍须独立比较认证时间和全部成本。

## 3. 独立微型运输 LP oracle

构造两个站点小支持（含相同/不相同的比率点），用端点 `e∈{a,b}`、状态对 `(y,z)` 的非负变量 `π^e_yz`。目标 `min Σ_{e,y,z} π^e_yz |r_i^y−r_j^z|`；边际约束对每个站点状态满足 `Σ_{e,z}π^e_yz=s_iy`、`Σ_{e,z}eπ^e_yz=q_iy`，对另一站同理；`Σπ=1`。`a=b` 只保留一个端点层，oracle 应等于 B1。用独立于切割代码的精确有理枚举/LP 对小支持求值，比较 B1 的单层运输值及 B2 公式；保存 primal、dual 或可复算的耦合矩阵、目标差和有理数据。生成的 `(s,q)` 必须满足两站同一个 `G`，可先由随机有理端点耦合得到，再加入特制分数点。

枚举全部小实例整数 one-hot 状态与 `G∈{a,(a+b)/2,b}`，验证每条生成行和真实 `h=|r_i−r_j|`，另抽查 `h` 至源码统一上界。覆盖 `a=0`、`a=b`、极窄正宽、端点层零质量、两站比率重合、异质 target、单点/双点支持、全零库存及 `S=0` 原问题约定。反例测试把 `[0.5,1]` 的 B2 行故意放入 `G=0` 父域，必须发现误删；把缩窄支持省略系数行放宽域也须拒绝。数值测试保留未归一化 B2 行、行尺度与残差，不能以剪裁负层质量或更改求解器容差让测试通过。

## 4. 正式实施准入

只有一般证明、独立 oracle、全部微型整数点检查、真实 LP 违背和固定 LP 成本审计通过，才将 B1/B2 接入完整求解。入口为叶的 `writeCanonicalCompactModel`/`writeCompactLp` 或新鲜 canonical 模型上的合法追加行；所有 B2 行须绑定并记录叶 `[a,b]`、支持域、模型 SHA256，生成后纳入模型哈希与行签名。父叶行可留给子叶，子叶特化行不可回传父/兄弟。模型重建、callback、分离及验证时间必须计入完整运行，不可设置内部秒数/Work 切片或按实例历史表现启停。G3 后方能谈端到端时间；固定 LP 的下界改进不是认证加速。
