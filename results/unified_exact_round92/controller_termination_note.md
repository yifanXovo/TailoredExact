# ENS-C 的 C6 调度有限性：源码限定的条件证明

审查范围是当前默认 `research-round83-vds-equal-net-exchange` 的 first-class K1/C6 路径，不把可选的 Round42–49、Round61/65 或 LP-G 变体混入结论。预设继承见 `src/main.cpp:270–274,298–351,354–365`、`src/PaperK1AmSf.cpp:53–66,110–116`；默认 `round42_terminal_sibling_coalescing`、`round43_envelope_refinement`、`round48_k1_amf`、`round49_k1_am_rc`、`round61_candidate_mode`、`round65_budget`、`round90_lp_g_split` 皆关闭（`include/Instance.hpp:41,483,499,530–561`）。因此下面只论默认中点、AM、frontier/native-target、父叶 terminal MIP 的控制循环。

**命题（条件性无无限重排）。** 固定有限实例，假定每次完整 LP 和原生 MIP 调用最终给出源码接受的终态，或者全局截止/工程门禁使整个运行停止；模型写入及账本操作也有限完成。再假定已验证 incumbent 只来自有限路线/整数库存状态，模型/子 LP 同一 epoch 的身份检查按源码执行。在这些前提下，默认 C6 调度不可能在截止之外无限次 requeue；若所有被启动的终端 MIP 可靠终止且无工程失败，有限次循环后所有相关叶关闭或被有效界排除。这是**控制器**有限性，不是每次 native 调用的运行时间上界、求解器数值可靠性证明或多项式复杂度结论。

证明不靠“IEEE 状态有限”或每次下界至少提升固定量。根仅一个区间、二分深度小于 8 且宽度大于 `1e-4+1e-12` 才可分（`src/PaperK1AmSf.cpp:57–63`、`src/GiniFrontierGeometry.cpp:362–369`、`src/PaperExternalGiniTree.cpp:6172–6179`），故一个 epoch 内可能出现的二叉叶 ID 至多 `2^9−1=511`。原子分裂/单子收缩替换父叶；双侧不可行直接闭父，均不复活该父叶（`src/PaperExternalGiniTree.cpp:7273–7467`）。每次 incumbent epoch 增长都以独立物理验证并满足 `objective < verified_ub−1e−9` 为条件（例如 `:4030–4041,8664–8680`）；有限原路线/库存状态使这种严格改善次数有限。epoch 变动废弃旧 canonical LP 与子缓存（`:3499–3526`）。故若存在无限调度序列，最终必落在某一固定 epoch 和有限个叶 ID 中。

在这个固定 epoch，每个叶只能经历有限个可重复选择的阶段：

1. 父 LP 完成后按 epoch 缓存（`src/PaperExternalGiniTree.cpp:3611–3615,3684–3714`）。`selected_leaf_no_longer_controlling` 的无 native 重排（`:6082–6107`）只可能由**本次新 LP 提升**使先前选择过时而触发：`selectNextByBoundOnly` 原本只选全局最小界 `+ tolerance` 内的叶（`src/ControllingLeafScheduler.cpp:611–686`），同一 epoch 再用缓存 LP 时不会使该叶忽然比另一个开放叶高出 tolerance。因此它不能对同叶无限自环。
2. 若存在更高的严格 frontier 界，`next_leaf` 原生目标严格大于当前界 `+ certificateTolerance`（`src/PaperExternalGiniTree.cpp:833–878,3861–3867`）。成功到达而未闭合时，置 `c6_frontier_milestone_reached=true`（`:4097–4136`）；以后同叶直接允许子 lookahead（`:860–865`），不会再次发起这个 frontier 目标。未到达若原生 MIP 已 OPTIMAL/INFEASIBLE 则闭叶（`:4052–4091`），截止则停止，非法证据则失败停止。标记在源码中只有初始化为 false、成功后置 true，没有同一叶复位分支（`:145,4104`）。
3. 两个完整子 LP 在同一 epoch 缓存（`:6257–6271,6342–6437,6588–6621`）；实际复用时还核 child ID、区间、模型 SHA、LP epoch 等身份，身份不符是失败而非默默重求（`:6355–6416`）。若两侧均有限且 `t=min(B_L,B_R)>B_parent+tolerance`，AM 要么立即原子分裂，要么运行一次以 `t` 为目标的父 MIP；若无严格增益则直接请求父 terminal MIP（`:1025–1071,6634–6642,7729–7732`）。目标成功重排必须满足原生有效界 `b_native+tolerance>=t`，且 `mergeValidLowerBound` 把父界设为 `max(B_parent,b_native)`（`:4017–4028,4097–4110`；`src/ControllingLeafScheduler.cpp:358–385`）。下次同 epoch 使用**同一**子 LP 时，新的父界 `B'` 满足 `t<=B'+tolerance`，于是 AM 必走 `adaptive_mass_no_strict_child_improvement` 并进入父 terminal MIP（`src/PaperExternalGiniTree.cpp:1058–1069,7729–7732,8518–8534`）；不会再次发同一 child 目标。即使父界只增极小量，这一布尔谓词仍给离散进展。若期间先发一次尚未使用的 frontier 目标，第 2 点的 milestone 使其最多一次；随后仍回到此缓存判断。
4. terminal MIP 同叶至多启动一次；再次启动被 `paper_same_leaf_terminal_mip_restart` 拒绝。可靠 OPTIMAL/INFEASIBLE 后关闭，截止则停止并保留开放覆盖（`src/PaperExternalGiniTree.cpp:8518–8534,8645–8652,8694–8727`）。一次选择至多产生新的已知子 ID、以上阶段标记进展、终态或整次停止。有限 epoch 与有限 ID 排除了无限 requeue。

**数值与论文边界。** 在精确算术抽象中令 `tol=0`，目标成功给 `B'≥t`，下次同一子界的增益不再严格为正。当前 binary64 路径则使用程序比较层面的链条：同一缓存的 `t` 被用作 target，成功门槛为 `b_native+tol>=t`，而下一次 `B'=max(B,b_native)`；有限且非 NaN 的数值和相同 tolerance 下，`B'+tol>=t`。它不要求 native bound 比旧界至少增加 `tol`；`target>B+tol` 与 `b_native+tol>=target` 只保证严格增大，允许任意小的正增量。恰是缓存加“无严格子增益→terminal”阻断了趋近上界的无限成功重排。LP/原生状态、界和模型的有效性仍依赖项目已有浮点残差、指纹及终态门禁；没有独立有理证书。不能把一次 `target_reached_requeue`、`proposed_exact_parent_closure` 或 terminal 启动写成实际证明闭合。

前提的必要性可用状态路径说明，但**不是当前默认源码可达的 bug 断言**：若在同一 epoch 中每次成功 child-target 后悄悄丢掉已完成子 LP、下轮又生成略高的新 `t_k>B_k+tol`，并只得到 `B_{k+1}=t_k−tol`，可选严格递增且有界的 `B_k` 无限序列；有限深度/整数路线本身不会阻止这种调度循环。当前默认实现正是以缓存与同 epoch 身份门禁排除该路径。相反，若某个外部原生/LP调用本身永不返回，控制器势函数无从推进；实际全局截止提供 `unknown` 退出而非认证（`src/PaperExternalGiniTree.cpp:4253–4270,4138–4149`）。本证明不得推广到未逐条审计缓存和状态复位规则的可选调度变体，也不得据此移除现有 depth 8 或全局截止。
