# Standalone resource-penalty propagation on stable GI-TBC

B is the complete stable R137 GI-TBC algorithm with GD, STOCK, AP and Shared-S off. P adds uniform root penalty caps; C adds one effective conditional cap per state directly to B. The unique complete candidate was frozen as C before any complete B/C result. The existing R149 GD+PF entry keeps its original definition and prerequisites.

For actual binary64 matrix coefficients, let h_i(y)=omega_i |c_i y-1|, where omega_i is read from the objective and already includes lambda. Existing epigraph rows give P_e=sum omega_i e_i >= sum h_i(Y_i); the arm's own non-strict cutoff gives g+P_e<=U0. The root resource relaxation keeps the support boxes and Bminus<=sum Y_i<=B, while relaxing support holes, integrality, routes and time.

Choose one finite pair mu,nu>=0 using the existing resource allocator. Put a=nu-mu, m_i=min_box(h_i(z)+az), and d=mu Bminus-nu B+sum m_i. The local minimum needs only the two endpoints and the kink 1/c_i when enclosed by the box. Selection of the multipliers is approximate; weak-dual validity depends on the conservative evaluation at the actual finite multipliers, not on the greedy diagnostic primal being optimal.

For fixed Y_i=y, define d_iy=mu Bminus-nu B+sum_(j!=i) m_j+h_i(y)+ay. Since h_i(y)+ay>=m_i, d_iy>=d. At every resource-feasible vector, mu(Bminus-sum Y)+nu(sum Y-B)<=0, so d_iy is a lower bound on the fixed-state physical penalty. No GD row, Gini-Hoover inequality or STOCK identity enters this proof.

Use p0=max(0,down(d)), p_iy=max(p0,0,down(d_iy)), beta0=min(gamma_U_root,up(U0-p0)), and beta_iy=min(beta0,up(U0-p_iy)). P adds t_iy<=beta0 s_iy. C adds t_iy<=beta_iy s_iy directly, retaining the B rows. For an unselected integer state s=t=0. For a selected state, Y_i=y and t=g; hence the original cutoff and the penalty lower bound imply the new row. This also preserves every original feasible nonminimal g/e completion. It does not require g to equal physical Gini.

The production implementation reuses qualified outward interval primitives and the existing multiplier selection. It builds conservative prefix and suffix sums of local minima, then adds the resource constant, the two disjoint sums, and the current state cost. It never subtracts a separately rounded local lower bound from a separately rounded global lower bound. The cap-propagation pass after fixing the multipliers is O(n+sum support sizes). The inherited multiplier allocator sorts station slopes and takes O(n log n); child row filtering also uses support lookups. There is no conditional optimization, source solve, extra root LP or new column.

The cap vector is computed once, after the current arm's own H and root support/cutoff construction, before its first formal Optimize. It is frozen for compatible descendants: same input and objective coefficients, identical physical resource limits, subset support, a non-expanded gamma interval and a non-increased cutoff. Original AM geometry, threshold .08, depth8 and minimum width 1e-4 stay unchanged. Each state is tested against the current gamma_U separately. A dominated uniform cap does not imply all conditional caps are dominated. No minimum conditional cap becomes a global g bound. A cap below gamma_L only empties that improving state branch; a negative cap is retained as a valid signed row.

Actual P and C use the same monotone upward transport T: negative tiny caps in (-1e-12,0) map to 0, zero stays zero, positive tiny caps in (0,1e-12) map to 1e-12, and other values stay unchanged. Thus T(beta_iy)<=T(beta0) and T(beta)>=beta. Zero cap uses an exact single-term t<=0 row. A row is omitted only if its transported cap is dominated by the current original upper bound. Therefore actual Q_C is contained in actual Q_P, which is contained in Q_B, including uniform-only states and tiny/zero transport. No duplicate PF layer is appended to C.

For a station block, nonnegative selectors summing to one, product masses summing to g, and gamma_L s_y<=t_y<=beta_y s_y describe the convex hull of the state-dependent intervals: for positive s_y, set g_y=t_y/s_y and mix the branch points with weights s_y. This is a local block hull. It is not the joint hull of interstation resources, routing, loading, time and the integer objective. R133's integer objective epigraph obstruction remains unresolved, including at fixed denominators.

Four evidence levels stay separate: integer/completion validity and local inclusion; separation of a saved point; fully free same-domain LP values; and complete own-H finite algorithm outcomes. Point violation alone is not an optimum. LP improvement alone is not a complete algorithm benefit. Numerical LP qualifications are not exact rational optimality certificates.
