# Root decision on the fixed travel/activation LP diagnostic

Accept the six fixed original-F LP observations and independent review (`handling_real_independent_evidence_review.md`, SHA256 `0404e0e0c78e9838794bc13da61170740585f68ade569f455a44fc2119af6bc4`). D3 has no numerical lower-bound gain: all three arms give 0.0282826776207786. C2 improves from 0.602666467698065 to 0.620202596583893 with the continuous travel/activation row, and to 0.622642579074402 with its integer floor. The extra 0.002439982490509 from B to C is the observed rounding contribution; the entire C-minus-A gain must not be attributed to rounding alone.

These are solver-numerical fixed historical L0 optima with unchanged original objective, cutoff, G domain, matrix and tolerances. The historical U is only offline diagnostic context. All six have complete primal/row/bound receipts; the later archive independently hashes all 47 raw files, including the 18 large files initially indexed from solve receipts, and verifies the complete compressed member stream. That establishes byte integrity, not an independent rational dual certificate or a second numerical residual computation. Originals remain in place.

The positive C2 effect and small row count justify preparing one uniform static-row candidate, after the active Round90 source freeze permits integration. It should add only the rounded travel/activation row per vehicle, under the reviewed structural and coefficient-validity assumptions, to the original ENS-C. Do not combine it with LP-G at this stage, tune a travel bound family, or select cases at runtime. The continuous row is an already studied diagnostic comparison, not another formal algorithm to select per instance. Existing R7/R8/R63 relationships and the limited two-dimensional aggregate convex-hull statement must be disclosed; this is not a new general cutting-plane theorem or the routing model's convex hull.

Before any real method screen, the implementation needs a reviewed link to the actual canonical duration/depot/flow coefficients, safe exact rounding, and focused boundary validity checks. Shared coefficient construction with a verified canonical writer is acceptable; repeated whole-model parsing is not a mathematical requirement if the same correspondence is proved by construction. A full-method test must include the zero-gain D3 case and the already fixed protection roles. Apply the existing finite early-stop standards. A root-LP improvement alone does not admit the row to the final method.

This decision authorizes source preparation and an implementation proposal, not an immediate build or Optimize. Current LP-G G4 source/binary/protocol hashes remain frozen. The next integrated candidate and its finite run identity must be registered separately. If complete-method costs or protected performance are unfavorable, park this one row family without a parameter search.
