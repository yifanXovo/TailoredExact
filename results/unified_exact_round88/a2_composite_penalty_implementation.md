# Round88 A2 composite penalty flow: static implementation

Status: new research-only prototype and independent micro-qualification source are frozen for static mathematical review. **No code, tests, solver, compiler, real endpoint probe, or archive operation has been run for this variant.** The original A2 flow/probe, native ENS-C code, and D6/E8/S12 negative results are unchanged.

## Scope and difference

`scripts/round88_quantity_composite.py` reuses only the frozen A2 fixed-route domain, integer min-cost circulation engine, physical prefilter, primitive line construction, and verifier callback interface. It does not substitute a new gradient into the old oracle. At current inventory it computes the exact rational local generalized gradient of the Gini ratio, with zero sign for ties and `S=0` rejection. For each visited station it keeps the entire convex `lambda * weight * abs(y / target - 1)` term: exact pickup/drop integer marginals from **original stock** become parallel arcs, and only consecutive equal rational marginals are merged. An LCM converts every arc cost to an integer. Nonvisited stations still enter S, H, and gradient, while their proxy contribution is constant.

The returned certificate includes every marginal arc, original network primal and residual potentials, and per-station raw pickup/drop, cancellation, projected inventory, and exact proxy cost. Postchecks require marginal prefixes, telescoping raw costs relative to original stock, no increase on same-station cancellation, unchanged net inventory, fixed-network domain membership, and equality of the optimal raw-flow and projected-proxy costs. The unchanged original verifier callback remains mandatory for the current point and each physically admissible point on the complete primitive integer segment. Only a strictly lower **original** objective is accepted. The Gini local gradient is not a global supporting bound; this certificate proves only the fixed-template proxy optimum.

There is no new internal iteration count, step size, time budget, random restart, or instance-dependent choice. `run_composite_oracle` performs one complete proxy solve and one full primitive-line check. A real C++ `incumbent-import-test` adapter for this *new* module has not been written or invoked; callbacks in the source test are test doubles. Any later real endpoint probe needs a separately reviewed, explicitly named adapter and the original native receipt checks before evidence about D6/E8/S12 can be claimed.

## Unrun qualification source

`tests/round88_quantity_composite_test.py` contains direct Fraction stock-objective and Gini-gradient calculations independent of arc generation. It enumerates 216 two-station configurations across initial stock/capacity, zero and positive vehicle capacity, empty and multiple routes, service deadlines, and penalty weights, comparing the network's returned stock and value with independently enumerated feasible integer inventories. For each configuration it independently rebuilds the full arc list, capacities and costs, verifies integer flow balance and objective, and checks every positive residual arc against the returned potential certificate. Other cases cover the hand-calculated two-station improvement, a rational target between integer stocks with three marginal segments, integer/out-of-capacity targets, zero weight, zero capacity/budget, loaded return, no-gradient/no-direction outcomes, complete primitive-line callback calls, and over 1,000 exact same-station cancellation tuples.

These are static test definitions, **not pass claims**. After the compute slot is released, qualification must run the tests, preserve exact command/interpreter/hash/elapsed time and all failures, and obtain independent review before any real endpoint diagnosis. Even passing these tests would not establish improved native ENS-C performance.
