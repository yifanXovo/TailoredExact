# R105 capability and evidence boundary

The implementation is default-off (`--round105-decomposition off|full|core`).
P-GRB keeps its original compact model and cold launch; ENS-C keeps its paid
startup and AM. This prototype uses that paid startup followed by one global
assignment master. It does not add R104 resource preprocessing.

The nine diagnostics include F2/F5 nonoptimal integer incumbents only as
mode sources; only optimal master events enter the production loop. The
first C2 production proof repeats the previously qualified mode in a fresh,
paid run, without importing that proof. Diagnostic and production proof
events are separate counts; adding them does not establish a distinct-instance count.

F2 FULL/CORE use identical first master bytes and each has zero oracle/IIS
calls. Consequently that full/core ablation does not measure core search
strength. Real cores prove a strictly larger Boolean forbidden conjunction
than complete modes, but do not establish a count of additional feasible
master points excluded or a speedup. Current long/new confirmation status
and performance verdict are in final_report.md/admission_decision.json.
