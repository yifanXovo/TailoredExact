## Change

Round88 found useful inventory-CDF relaxation strengthening, but its repeated-LP service and eager full-family epigraph were too costly to advance. This default-off prototype separates B1 rows inside ENS-C's existing native MIP search, without a second Optimize service or a full auxiliary matrix. It adds `--round89-native-ot-b1 true` for the R83 preset and identifies the candidate separately; reference ENS-C and P-GRB defaults remain unchanged.

The separator audits the actual VD-P inventory/state and ratio/inventory links, constructs signed CDF rows on the imported model's support, and conservatively accounts for support multiplication and row-coefficient rounding. It submits every reliably violated pair row at an optimal MIPNODE, without internal time, Work, row or pass quotas. Terminal and partial-bound proof MIPs share this rule; ordinary LP probes remain unchanged. PreCrush=1 is the only new production solver setting. Callback work counts toward the original complete-run deadline, and API/model errors invalidate the candidate call instead of retrying as baseline.

Production evidence records per-MIP identities, counts, skip reasons and costs. Successful API submission is not described as permanent solver acceptance. Startup, AM gate, split policy, mathematical proof targets and certificate tolerances are unchanged.

## Validation status

The implementation and isolated test harness compile and pass the final [independent static review](results/unified_exact_round89/native_ot_b1_independent_static_review.md). Initial review found an ineffective floating-environment guard, a missing genuinely rounded-product test, an expensive repeated matrix scan, and failure-path bound events that could be reported as valid. Targeted revisions also cover final native log/status API failures. All findings and repairs remain recorded.

Qualification has run twice. The first batch passes Round53's 30 cases and Round55's 58 checks, then stops before Optimize because a test fixture's inventory bounds disagree with its six states. After a two-bound fixture-only correction, Round89 pure checks and the independent exact-dyadic oracle pass **54 integer-state checks**, including genuinely rounded support products. One native invocation completes all six toy Optimize arms: direct off/static/callback return objective 1, actual-backend LP returns 0, and terminal/partial MIPs return 1 with valid B1 model audits and PreCrush=1. However, **no usable MIPNODE event or GRBcbcut submission occurs**. The callback qualification is inapplicable; no real-instance run or speed claim is admitted. See [first-batch review](results/unified_exact_round89/qualification_001_independent_review.md) and [second-batch review](results/unified_exact_round89/qualification_002_independent_review.md).

The two earlier batches cost 3.751s and 3.861s at non-overlapping outer wrapper boundaries, with six total Optimize calls. Original failed/partial receipts are retained. The second batch's final failure receipt overwrote its direct toy primal payload, so those objectives are not represented as independently audited witnesses.

A replacement parity fixture with integer optimum 1 and LP value 0 now passes [qualification003 and independent review](results/unified_exact_round89/qualification_003_independent_review.md). Its six arms complete in one invocation: direct callback and both production MIP paths each submit three reliably violated B1 rows with API success. Direct original-row/bound/integrality residuals are zero, and the backend LP remains inactive. Each arm persists evidence immediately; backend MIP primal remains explicitly unavailable. This changes only the test harness. Two Micro-only builds cost 3.672s and 3.703s; batch003 costs 0.501s outer wrapper wall, with six additional Optimize calls. These results qualify the API/integration path, not speed or a new physical certificate.

The bounded eight-role ENS-C/native-B1 runner passes source review and a 0.1252175s zero-Optimize identity/command check. It preserves whole-run deadlines and original evidence replay; per-call B1 summaries join uniquely to the Optimize ledger. Old canonical LP bytes may be unavailable after incumbent-epoch replacement and are explicitly reported as such. Contemporary ENS-C/native-B1 pairs use one binary; Round88 P timings remain historical unpaired context. Four small smoke arms precede separately admitted remaining pairs. This draft neither promotes a mainline algorithm nor starts a broad long-run campaign.
