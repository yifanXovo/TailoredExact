The existing evidence reader checks original physical witnesses, coverage, native parameter readback when native calls occur, and scoped bounds. Abnormal process exit and failed audit stop the stage; valid deadline-censored evidence remains open. The severe rule is unchanged: paired certificate slowdown above 1.5× and 30 s (5 s on jointly certified sub-60-second smoke arms), severe certificate loss, or both-open gap deterioration above 1.5× and 0.01 (`round92_handling_g3.py:268–365, 468–609`). A candidate floating-environment/witness rejection must therefore not become a fallback result.

This is **not** execution qualification or a performance finding. The root must separately issue the pinned gate, run zero-Optimize preparation, inspect that receipt, then decide a smoke lease; rest needs an independent smoke acceptance and new lease. The accepted G1 boundary still applies: the new row's physical envelope was checked, but the inherited canonical duration serialization can exclude a physically accepted route on arbitrary real-valued inputs, so these experiments cannot be advertised as a rational proof for the full original-real-input model or as P-GRB superiority.
