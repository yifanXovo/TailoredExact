# Round88 原生 B1 user cut：最小设计合同（只读）

**结论：值得做一次最小 native prototype 的资格验证，尚不准入正式求解或宣称更快。** 它与离线反复 LP 服务、预建全族 epigraph 有可检验的结构区别：仅在同一原生 MIP 的 `MIPNODE` 事件提交 B1 原列切割，不另建 LP 服务或 O(全族) 辅助矩阵。每次回调及求解器重优化都属于原证明成本；不存在内部秒数、Work、轮数、行数配额或实例分派。新研究身份默认关闭，现有 ENS-C 与容差保持原样。[稀疏 epigraph 决策](ot_epigraph_decision.md)尚无 D7 完成界，不能转化为 native 性能承诺。

**真实路径与 API。** ENS-C 的 `round55-vd-p` 对应 `f0-clean-none/c0-baseline`，当前未启用 CDF user cut。`PaperExternalGiniTree.cpp` 不仅在约 8201 行发起 `PaperTerminalMip`，还在约 3837、7172、7597 行发起 `PaperPartialBoundTargetMip`；最小候选若宣称覆盖原生证明 MIP，必须在这两类实际 native Optimize 中执行同一规则，普通 `PaperLpRelaxation` 不走回调。`GurobiBaseline.cpp` 约 1629 行读 canonical LP，约 2512 行注册已有合并回调。现有 R53 分离器在约 1113–1125 行只拷 `p_`,`z_` 值，并在约 1169 行早退；不能直接接 OT，也不能破坏其它 MIPNODE 观测、MIP 进度/界目标/证据回调。必须在 Optimize 前按 canonical 模型 SHA、叶 id/域、完整整数支持核唯一列索引、类型与界，以及 `state_i_y`、`r_i`、`h_i_j`、one-hot、`r` 重建和 `h≥±(r_i−r_j)` 原行；`state_g_i_y` 虽不入 B1 行，也须确认 VD-P 模型身份。对 retained 模型/partial target 再次核指纹，避免把另一叶索引复用。

官方 Gurobi C 文档规定 [`GRBcbcut`](https://docs.gurobi.com/projects/optimizer/en/current/reference/c/callback.html#c.GRBcbcut) 只可在 `GRB_CB_MIPNODE` 调用，切割不得排除满足原约束的整数解；[`MIPNODE_REL`](https://docs.gurobi.com/projects/optimizer/en/current/reference/numericcodes/callbacks.html) 仅在该节点 `STATUS=GRB_OPTIMAL` 时读取，返回点**不保证**对用户原模型可行。故非最优节点只记录跳过；最优节点取完整原列向量，值非有限则跳过并留因，**不**把其原行残差当 solver 错误或作为切割有效性的前提。根节点可能在多个 cut pass 重复回调。设 [`PreCrush=1`](https://docs.gurobi.com/projects/optimizer/en/current/reference/parameters.html#parameterprecrush) 并回读，记录其对 native 成本的影响；这有助原列 cut 映射，但 `GRBcbcut` 返回 0 只记 `submitted_api_ok`，不证明该行已成为永久活跃的内部约束。不能将后来再次可靠违反同一已提交行当数值错误；单次 callback 内按规范化原行去重，跨 callback 可重提并分别记日志。不要改 `CutPasses`、原生容差或其它参数来隐含配额，也不用 lazy constraint 代替 user cut。

**更正后的实际 VD-P 数值模型。** 先前把 VD-P 误作直接 `r_i−Σ_y(y/D_i)state_i_y=0`；源码中的直接重建行只在 `vd-j` 写出（`CplexBaseline.cpp:2893`）。ENS-C 的 VD-P 实际保留两条链接：`Y_i−Σ_y γ_iy state_i_y=0`（约 2837–2887 行），`r_i−α_iY_i=0`（约 2110 行）。`γ_iy` 是导出模型中对应整数 `y` 的 binary64 系数，`α_i` 是实际导出 `1/D_i` 系数；即使两者都是可表示数，**精确乘积** `τ_iy=γ_iyα_i` 未必是 binary64。故先前“直接取 `r` 链 binary64 支持使 `δ_model=0`”对 VD-P **不成立，不能作为实现合同**。必须从实际读入 canonical 模型核两链接的单位主系数、零 RHS、每个状态系数、one-hot、有限 `r_i` 界及 `h_ij≥±(r_i−r_j)`；有缺失、重复列或不符则禁用本 cut。名义物理 `y/D_i` 只作解释，不代替实际模型系数。

**唯一首选实现：有限 double 节点加两层误差外包。** 对每个状态令 `β_iy=fl(γ_iyα_i)`，只在有限时使用，按 binary64 的**数值**精确排序、相等合并（`+0/−0` 视同一值；不同状态列仍全保留）。乘法结果用 `nextafter(fl(γ α),−∞/+∞)` 包围精确 dyadic 乘积 `τ=γ α`；由该区间向上求 `e_support,iy≥|β_iy−τ_iy|`。须确认 IEEE binary64 正常舍入、无 fast-math/flush-to-zero，且乘法及区间端点有限、无溢出，否则该模型/行不提交。对站点对设 `δ_model=max_y e_support,iy+max_z e_support,jz` 的向上界。有限 `r` 界需核身份和系数规模；即使某个状态的精确 `τ` 落在界外，它只可能减少实际可行整数点，不能据此消去状态列或放大 cut。

两站合并节点 `v_0<⋯<v_m` 后，令 `Δ_k=v_{k+1}−v_k>0` 的**精确 dyadic 差**。任取 `σ_k∈[-1,1]`，在原 `state` 列形成 `R_β=Σ_k Δ_kσ_k(C_i(v_k)−C_j(v_k))`。对 one-hot 的状态 `y,z`，`R_β≤|β_iy−β_jz|≤|τ_iy−τ_jz|+δ_model=|r_i−r_j|+δ_model≤h_ij+δ_model`。这条有效性与当前节点 G 域、回调点的原模型残差无关。符号可由普通浮点 CDF 选，零固定 `+1`（或 0）；错误符号只会使行较弱，不会排除原整数点。每个最优 MIPNODE 对每对站点生成其当前点的一条符号行，提交所有可靠违反的不同 pair 行，无额外行数上限；只有一个合并节点则没有区间或有用 cut。

一趟**倒序后缀**足以展开：`R_m=0`，`R_k=R_{k+1}+σ_kΔ_k`（`k=m−1,…,0`），位于 `v_k` 的 `i/j` 状态系数分别 `+R_k/−R_k`。这是直接段和的精确代数式；同值碰撞的不同状态取得同一系数。对 `Δ` 减法和每步后缀加法以 `nextafter(·,−∞/+∞)` 包围 exact dyadic 运算，负号交换端点；若任何端点非有限、溢出或执行环境不满足舍入前提就跳过。选有限 binary64 提交系数 `\hat c`，从包围区间向上算每列 `e_coeff,y≥|\hat c_y−c^*_y|`，再取 `δ_coeff=max_{y∈Y_i}e_coeff,y+max_{z∈Y_j}e_coeff,z` 的向上界。于是每个**精确满足实际导出 MIP 约束**的 one-hot 整数点都有 `h_ij−Σ\hat c state ≥−(δ_model+δ_coeff)`；RHS 必须向 `−∞` 舍入，含支持乘法和行系数两项外包，不能只补其中之一。

回调活动值须用实际提交 binary64 系数及 callback binary64 向外区间点积（或精确 dyadic 计算）。若 `U` 是活动值上界、`r_d` 是提交 RHS，至少要求 `r_d−U` 严格大于回读且未修改的 native `FeasibilityTol`（当前 `1e−6`；显式等比例行缩放需同步换算）才记 `reliably_violated`。这不保证求解器永久接纳 cut，也不把近容差整数候选当数学证书；原物理验证继续。非有限值、区间失败或太近容差只跳过并留因，不能声称切割族已闭合。

独立无求解 oracle 须把 `Fraction.from_float(γ_iy)*Fraction.from_float(α_i)` 作为**实际模型整数 r 值** `τ_iy`，把 `Fraction.from_float(β_iy)` 作为切割节点，两者不得混用。枚举小支持所有整数状态及 `±1` 符号，以 `h=|τ_iy−τ_jz|` 核实际提交浮点行加保守 RHS 不删任何原整数点；另把一趟后缀包围与直接精确 dyadic 段和比较。覆盖 `τ` 乘积不能用 binary64 精确表示、不同 `τ` 撞到同一 `β`、相邻 binary64 节点、`±0`、单点支持、有限 `r` 界、溢出/非有限拒绝和原行不可行 callback 点。完整独立 oracle 不以 `Fraction(y,D_i)` 或错误的 VD-J 直接链接代替上述两链接。

**最小资格与风险。** 先做上述两链接 dyadic 整数 oracle，并核每个符号行、碰撞阈值/零段、满/空 CDF、两项保守 RHS 和人工原行不可行的浮点节点向量。随后一个隔离的原生两站 MIP 同时跑“无 cut/原列静态 B1/回调 B1”，核三者原整数最优与物理验证一致、回调点可违反、`PreCrush` 回读、实际 `GRBcbcut` 返回码、root 多次 MIPNODE 时序和 cut 再提行为；如无合格 MIPNODE 事件则资格为不适用而非通过。静态调用链和微型运行要分别证实 terminal 与 partial-bound MIP 均接入，普通 LP 不接入，原全局 deadline/证据及完整成本计费不变。若数值外包不可证明、原生回调未产生可审计有效切割，或成本过高，应停止此方向；一次 API 成功或一次根界改善都不等于正式 ENS-C 多实例运行优势。
