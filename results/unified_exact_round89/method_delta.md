# Round89 native B1 prototype — implementation method delta

Status: source and isolated micro-test compile; **no test, toy Optimize, real LP, or real MIP has run**. The feature remains default-off and requires a separate qualification lease before any executable evidence claim.

The only new run flag is `--round89-native-ot-b1 true`. `main.cpp` accepts it only with the frozen `research-round83-vds-equal-net-exchange` preset and rejects combination with Round88 A1. The snapshot uses identity `research-round89-ensc-native-ot-b1`. With the flag false, the existing policy, native parameters, startup, split, proof control, and certificates take their original paths. With it true, the Gurobi fixed-interval backend activates B1 only for `PaperTerminalMip` and `PaperPartialBoundTargetMip`; `PaperLpRelaxation` remains outside this callback. The candidate requires `round55-vd-p`, the canonical LP file SHA, nonempty leaf/scope/row signature, an audited actual Gurobi matrix, and `PreCrush=1` set/read back. It leaves `Cuts`, `CutPasses`, heuristics, MIP tolerances, thread count, and startup settings untouched in production. The model audit and callback occur inside the already paid proof call and subtract setup time from the candidate's Gurobi TimeLimit readback.

VD-P's actual chain is **two rows**: `Y_i−Σ γ_iy state_i_y=0` and `r_i−α_iY_i=0`, where `γ_iy=y` is verified coefficient-for-coefficient in the imported canonical LP and `α_i` is read from its imported ratio row. The direct `r_i−Σ(y/D_i)state_i_y` row is not present in this formulation. The audit also requires unique complete contiguous selector names/types/bounds, their `state_g` companions and G row, one-hot equality, finite `r` domain, and the two original `h_ij≥±(r_i−r_j)` rows. A missing or ambiguous identity row fails the candidate before Optimize. Original states with coincident nominal knots remain separate selector columns.

For each state the nominal knot is binary64 `β_iy=fl(γ_iy α_i)`; one outward `nextafter` on each side of that product encloses the exact dyadic product `γ_iy α_i`. Let `δ_model` be the upward sum of the maximum state-wise product error on each of the two stations. Distinct binary64 knots are sorted/merged, including signed zero; their segment widths and one-pass signed suffix sums are outward enclosed. For the submitted binary64 original-column row, `δ_coeff` is the upward sum of each station's largest coefficient enclosure error. The submitted inequality is `h_ij−Σ c_i state_i−Σ c_j state_j ≥ nextdown(−(δ_model+δ_coeff))`. This protects every exact solution of the **actual imported** two-link linear MIP at integer selectors; it does not equate its real-valued support with unrounded `y/D_i`. A sign chosen from a numerically imperfect MIPNODE vector still gives a globally integer-valid row. If the arithmetic environment, finite ranges, or outward enclosures fail, that pair is skipped and counted; no unprotected row is substituted.

At every optimal `MIPNODE`, the callback reads the complete original-column `MIPNODE_REL` vector. Nonoptimal nodes are counted without a vector read; nonfinite vectors are counted as safety skips. For each pair it computes the CDF signs with zero assigned `+1`, then constructs at most one row on that pair's unique `h` column. It submits **all** rows whose outward upper activity proves a violation strictly above the unchanged read-back `FeasibilityTol`. The binary64 RHS and original-column activity are checked after coefficient conversion; there is no internal time, Work, row, pass, or node cap. Pair-specific `h` gives within-callback deduplication; the same pair can be submitted in later callback passes. `GRBcbcut` return 0 is recorded only as API success, never as solver acceptance or permanent retention.

Canonical audit, parameter, callback vector, `GRBcbcut`, evidence-write, or other API failure yields an explicit Round89 failure status and stops the candidate. On a callback failure the backend terminates the native model. Any candidate engineering failure, including log/status API or domain-restoration failure, suppresses downstream bound/incumbent and native trace eligibility and makes the controller engineering gate fail; it does not retry as baseline. Per-row numerical rejection leaves the original MIP valid and is reported separately. Each candidate proof MIP writes `<native_log>.round89.ot_b1.summary.json` for source identity, precrush, tolerance, row audit, callback/pair counts, reliable/API-successful rows, skip reasons, and setup/callback seconds. Production does not dump per-node primal vectors or full submitted rows. These are method costs, not free offline work.

The isolated native toy uses two stations with nominal supports `{0,1,2}`: station 1 permits only endpoints, station 2 is fixed at the middle. Its original integer optimum is `h=1`, while the root LP permits endpoint selectors `(1/2,1/2)` and `h=0`; B1 gives `h≥1` up to outward safety slack. The `off`, original-column `static`, and `callback` arms are independent native models with toy-only `Presolve=0`, `Cuts=0`, `Heuristics=0`, `Threads=1`, and `Seed=0`; only the callback arm sets/read-backs `PreCrush=1`. The off arm exports its original LP, then three independent calls through the **actual production backend** exercise `PaperLpRelaxation` (negative control), `PaperTerminalMip`, and `PaperPartialBoundTargetMip`. These backend integration calls use toy-only `Presolve=0` but otherwise preserve the production callback/parameter path. Thus the isolated native command contains exactly **six** toy Optimize calls, with per-arm receipts. Qualification requires an actually observed fractional optimal MIPNODE and at least one reliable `GRBcbcut` API-successful submission, agreement of the three direct integer optima and original `h` witnesses, Round89 audit/activation in both production MIP paths, and inactivity in the LP path. If the fractional node is absent, the test is inapplicable, not a pass. A separate Python `Fraction.from_float` oracle checks the C++ pure fixture's actual two-link product, support/row error bounds, and all 3×3 integer states. Neither test has run at this stage.

The structural audit uses one CSR pass to index participating columns, then exact-matches candidate rows and rejects duplicates. The arithmetic gate uses a volatile run-time subnormal addition and MXCSR FTZ/DAZ read before audit or separation. Callback failure clears native bound events and target flags before controller trace writing. The expanded pure fixture covers genuine rounded gamma 3/5 products, merged and adjacent nominal knots, both CDF sign orientations, nonfinite bounds, support overflow, and unsafe FTZ/DAZ; the independent Fraction oracle checks 18 three-state sign-row points and 36 six-state genuine-rounded-product row points. These additions are compiled only and have not run.

The Round89 final engineering gate also clears all certificate eligibility and native bound trace events for any failed external gate, including log-parameter or domain-restore failure. A synthetic log-parameter failure outcome is tested alongside a clean-outcome control in the pure micro-test. The six-state rounded-product cut is checked end to end by an independent Fraction oracle at all 36 exact integer-selector pairs, including the submitted binary64 coefficients and RHS. These checks remain unexecuted pending the qualification lease.

The candidate also treats a failed or unsupported Gurobi Status attribute read as an external-gate error and clears proof/trace eligibility; the unchanged baseline retains its existing semantics. A synthetic pure-test outcome checks this gate. Still no test or Optimize execution.
