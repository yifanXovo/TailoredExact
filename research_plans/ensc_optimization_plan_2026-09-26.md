## 2. 统一的实验链

每项至少取得“有效且值得实现 / 有效但无实际松弛或运行价值 / 假设被反例否定 / 证据不足”之一。排除项保留证据；不要求所有设想都实现、更不要求所有设想都进入最终算法。

B1：库存状态分布的 Gini 切割
记 r_i^y=y/D_i，s_iy 为库存 one-hot 松弛；将两站状态支持合并为 t_1<...<t_m，A_l=C_i(t_l)-C_j(t_l)，C_i(t)=sum_{r_i^y<=t}s_iy。
候选不等式：
h_ij >= sum_l (t_{l+1}-t_l) |A_l|。
右边以每项正负号展开为线性不等式族；按当前 A_l 的符号可精确分离该对站点最违背的一条。
整数 one-hot 下右边恰等于 |r_i-r_j|，故有效；通过三角不等式可证明其支配均值差的绝对值。不等于保证完整耦合 LP 的根界严格改善。
验收：独立一般证明、微型点验证、真实 ENS 松弛违背证据、有效切割/耗时统计，再进入完整求解。先测 D3/D4/C2/F2 与 D7/U6/F5/F6，防止重现“根界强而认证慢”。

B2：利用 q=G s 的端点条件化 Gini 切割
对于 G in [a,b]，a<b：
u_i^a=(b s_i-q_i)/(b-a)，u_i^b=(q_i-a s_i)/(b-a)。
两端点层在不同站点分别具有相同的非负总质量。定义 B_l 为 q 的累计差，候选：
(b-a) h_ij >= sum_l Δt_l ( |b A_l-B_l| + |B_l-a A_l| )。
两个绝对值独立取符号，得到线性切割；a=b 使用 B1，不除以零。
整数点取值正确；三角不等式给出其对 B1 的支配。需独立复核：在“单对站点、one-hot、共同区间 G、q=Gs、距离上图”隔离块上，它给出投影凸包下边界。不得把此结论推广成含 Gini 比值、路由、资源约束的完整整数凸包。
重点审查区间局部性、子问题 cut 生命周期、窄区间缩放、端点与零质量层。先 B1 后 B2，比较增量价值。
不预设大量动态 cuts 必然胜过 root cuts；先用确定的完整分离规则研究。正式规则不得使用分离秒数/Work 截止。

B3：多站库存事件的车队不相容不等式
事件 E 由不同站点的非原始库存状态组成。若同时选择这些状态，则各事件必须分配给一辆实际服务车辆。
对分配子集 A，令 P_A、D_A 为被要求的取/放总量。一辆从空载出发的可行路线必满足有效旅行下界 + (c_pick+c_drop) max(P_A,D_A) <= T_k，并满足相应单操作与前缀载量必要条件。
若通过有效必要条件证明 E 的所有车队分配都不可行，则 sum_{(i,y)in E} s_iy <= |E|-1。
不能错误地使用“累计取车量 <= Q”；旅行下界必须对允许额外访问的真实路线有效。车辆异质性逐车处理。

C2：VD-P 乘积误差指导 split point
令 Y_i=sum y s_iy、Z_i=sum y q_iy、q_iy=s_iy g_iy，g_iy in [a,b]。则：
δ_i=Z_i-GY_i=Cov_s(y,g)，|δ_i| <= (b-a)(u_i-l_i)/4。
若 S=sum Y_i/D_i >= S_min>0，且模型有 n sum Z_i/D_i >= H，则：
G_true(Y)-G <= (b-a)/(4 S_min) sum_i (u_i-l_i)/D_i。
这是对分数库存处 Gini 低估的单侧界；不是整数解 gap、双侧误差或求解时间保证。S_min=0 时不可使用该式。
子域常数不变时，中点最小化最坏宽度误差；若有效传播给出随切点变化的 C_L(m)、C_R(m)，研究 min_m max(C_L(m)(m-a),C_R(m)(b-m))。
仅在 C_L/C_R 可视为固定正常数时可使用加权交点公式；不能把依赖 m 的量当常数求“闭式最优”。
先离线比较当前中点、理论误差与真实 child LP，再测试完整算法。B2 加强后重新分析 split 价值，不能直接叠加旧结论。

C3：零根界收益证据与 AM gate
若父 LP 的一个最优解可行地延拓到某子松弛、目标不变，并且子松弛真正嵌套父松弛，则该子最优值等于父值，两个子界的最小值不可能严格提高。
逐状态 q_iy=G s_iy 只能成为可行性检查的一部分；必须检查重建后的所有行、域、cutoff 和 epoch。聚合 δ=0 不能代替逐状态检查。
研究用便宜的完整可行性证书避免无收益 LP 探测。结论限于根界收益，不能声称分裂对后续 B&B 绝对无用。
先保留 AM .08，不进行盲目阈值搜索。只有新误差/无收益机制提供依据时才单独测试 gate 修改；正确性由覆盖保证，效率仍需实证。
