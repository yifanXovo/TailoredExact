# Independent framework for optional controls

This note is written while RB35-T2 OFF is running. It uses only the goal and
small existing reports/authoring scripts. It makes no prediction about RB35 or
K20 and starts no Optimize, build, heavy recovery or document export.

First complete the entered RB35 pair, then decide the still-unentered K20
pair. K35 currently has a material U/gap improvement with a moderate L loss;
RX20 certifies the same objective with about 1.42 seconds lower complete cost.
Neither justifies a severe-stop verdict. Judge the remaining panel jointly by
verified U, supported L, gaps, proof clocks and complete cost. Do not adopt a
new numerical severe-regression threshold after seeing a result.

| Control | Decision it could change | When it adds little value |
|---|---|---|
| One same-V5-PE K35 full-RN bridge, cap2400 | Whether RN-P's operational gain also holds against persistent RN, rather than only stable OFF; the core expression-cost attribution | A decisive important-role regression already closes the candidate and no claim comparing projected versus persistent RN is needed |
| One decision-critical Seed1 group | Whether the role carrying an adoption benefit or a serious tradeoff repeats under another Native seed | The evidence is already sufficient for research-only retention/closure and no concrete plausible reversal changes that judgment |
| One matched paid-floor comparison | Whether the PC's structural geometry adds useful full-search behavior beyond the same paid scalar root information | No adoption/attribution claim depends on that distinction, or implementing and qualifying it would outweigh its decision value |

If the complete core remains promising, prefer the already-supported K35 RN
bridge for the representation question. If RN-P improves against both OFF
and RN on the same finite joint endpoint/clock judgment, that supports an
operational advantage of this projected method in the tested role. If it only
improves OFF, report that limit. Neither outcome identifies column count as
the sole cause: geometry, cuts, AM paths and search trajectories can differ.
Historical R143 RN is context, not this same-PE control.

Seed1 is warranted only when an identified role controls the adopt/retain/stop
choice and its Seed0 result plausibly may not repeat. State that counterfactual
before freezing one full-window group. Compare the methods essential to that
decision at Seed1, each with its own H; H seed stays 20260626. Retain the whole
group, including an adverse result. This is not a general multi-Seed panel or
a reason to retry until favorable. A result-selected confirmation is labelled
as such.

The current paid-floor distinction is a rigorous local-block witness, not an
exact point in complete routing P and not an observed full-search comparison.
The prepared report correctly limits that claim. A paid-floor control is
needed only if a stronger structural-performance attribution or an adoption
choice would actually hinge on it. Such a control must obtain the same
current-run source at full cost, use a proof-policy-accepted lower bound, and
retain original objective, domain, H and complete validation. Floating source
primal ObjVal is insufficient. If additional code changes require a new PE,
the necessary comparison must preserve genuine same-PE identities; the old
core must not be relabelled. No floor implementation is proposed here.

Do not replace the primary panel's candid result with more controls. A clear
important-role regression permits research-only retention or closure while
preserving the real LP/primal information. A mild mixed panel may remain a
useful research boundary. Before each optional group, name the exact current
decision and which opposite outcomes would change it, check the actual single
28800-second budget including verification, and enter only that finite group.
Unused allowance is not a reason to run another method.

The report should keep the following statements separate regardless of which
control is entered: matched-root information retained; validity inherited but
descendant equality measured only once; compact zero RN columns; complete
RN-P versus OFF outcomes; projected versus persistent-RN attribution if tested;
and structural versus scalar-floor attribution only within its actual scope.
