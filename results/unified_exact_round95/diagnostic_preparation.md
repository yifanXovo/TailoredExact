# R95 fixed-witness G2 supervision: source preparation only

The source-only supervisor is `scripts/round95_full_block_diagnostic.py`. Its `validate` command has run once with the bundled Python and returned exit 0, `syntax_parsed=true`, `native_launched=false`; it checked the unchanged R93 manifest and exact D6/E8/S12 input/witness hashes in [full_block_diagnostic_preregistration.json](full_block_diagnostic_preregistration.json). No real candidate scan, G2 driver, native solver or production algorithm was launched by this preparation. The process job, kill-on-close, shared external deadlines and identity pre/post checks are a scoped adaptation of the frozen R93 supervisor (`scripts/round93_coquantity_diagnostic.py`, SHA256 `79a1440e6690e0299211149457cf112cfcaae9c79d5985133dd37f5b8000cd09`); the old script and R93 data are unchanged.

`run` has **two separate prerequisites**: a qualified G1 gate with schema `round95-full-block-g1-qualified-driver-v1` binding the R95 diagnostic binary, the R95 preregistration SHA and the six source hashes (`CMakeLists.txt`, R95 header, implementation, C++ diagnostic/tests and this supervisor); and a distinct root-created G2 lease with schema `round95-full-block-g2-run-lease-v1`. The lease must have `status="authorized"`, exact `qualification_gate_sha256`, `preregistration_sha256`, `harness_sha256`, `case_order=["D6","E8","S12"]`, `repetitions_per_case=1`, `whole_case_external_deadline_seconds=120`, `maximum_sum_case_deadlines_seconds=360` and a repository-relative `output_dir` equal to the requested fresh output directory. These files do not yet exist; this note supplies their schema contract, **not** permission or invented hashes. The script checks both before creating output, then rehashes the lease, gate, sources, binary, input and witness before and after each case. Reusing an existing output directory is refused.

For an authorized case, the diagnostic process receives the remaining time in its one 120-second case and the 360-second batch, with input parsing, baseline validation, all complete-block passes, observer logging, audit and receipts inside that shared external limit. The Windows job is assigned before the child sees its launch flag, so a timeout kills descendants. The supervisor preserves `command.json`, `bands.jsonl`, `intervals.jsonl`, `points.jsonl`, `acceptances.jsonl`, final witness, stdout/stderr, case receipt and batch completion. Root's separate PowerShell Stopwatch from actual batch launch through exit is the complete outer wall receipt; driver `summary.wall_seconds` and per-case pre-receipt clocks are nested/incomplete samples and never added to it.

The offline audit reconstructs each pass from the fixed input's initial stock, capacities and vehicle Q plus the accepted route chain. It independently derives every old-prefix 10/01/11 band, each `u` interval and its survivors, then demands the exact `(pass,a,b,u,v)` order for every load-surviving point. It checks `rectangle_points = load_pruned + candidate_points = load_pruned + evaluator_points`, physical/Evaluator flags and finite F/G/P for each surviving point, the `>1e-12` original-F best with `(a,b,u,v)` ties, zero-node route reconstruction, final original F/G/P equality and one terminal exhaustive pass. A committed integer-domain/nonfinite point or a reported `verification_failed` blocks completion even if a deadline is also reached. A timeout without such evidence is unknown; a nonzero native exit, identity drift, malformed complete receipt or supervisor fault stops the batch without retry. This audit verifies the **qualified driver's** original Evaluator receipts and route consistency; it does not claim an independent second implementation of original physical F.

The only permitted initial real diagnostic is the preregistered D6→E8→S12 sequence once each, with no source changes or extra cases after seeing outcomes. A positive isolated result remains mechanism evidence, not full ENS-C integration or an exact optimality certificate. Root must separately decide any later complete-method confirmation within this final third hypothesis.
