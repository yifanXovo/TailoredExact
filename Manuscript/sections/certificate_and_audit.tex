\section{Certificate Ledger and Evidence Boundary}
Each final Gini leaf records its interval, lower bound, closure basis, scope,
model fingerprint, solver lifecycle, and coverage state. A global certificate
requires a verified incumbent, complete improving-domain coverage, valid
closure of every final leaf, no invalid interval or open node, and a monotone
aggregate lower bound reaching the incumbent within tolerance.

Admissible leaf evidence consists of valid interval relaxations, exact
fixed-interval infeasibility, scope-valid Gurobi best bounds, and empty-domain
proofs. Same-run heuristic routes are upper bounds only and must pass
independent verification. Plain Gurobi, historical CPLEX rows, callback
vectors, diagnostic models, archived incumbents, and wrapper checkpoints do
not contribute to a K1--AM--SF certificate.

The Round 53 P-GRB benchmark originally omitted the pre-frozen expected-model-
fingerprint binding used elsewhere. Round 54 preserved every original result,
verified the original executable, froze 12 expected fingerprints before
correction, and rebound the existing rows. Expected and actual fingerprints
match for all 12; independent feasibility and objective checks pass. The
strict count changes from 0/12 to 9/12, while the three native time-limit rows
remain noncertificates. No Work, time, bound, gap, or GI value changed, and no
F0 promotion conclusion changed.

Source-scope, command, fingerprint, certificate, evidence-hash, and package
audits enforce this boundary. A finite-time bound is retained only with its
honest noncertificate status. Current qualification supports V12 and bounded
V20 use; V50 has startup/configuration evidence but lacks an opened Round 54
strengthening panel, so no universal scale claim is made.

Round 55 found that artifact and LP cache identities did not always advance
with a newly verified incumbent. The repaired key includes the incumbent
epoch on every relevant construction and reuse path. No false certificate was
observed, but pre-fix solver trajectories are not used as candidate
comparators. The corrected stable baseline was rebuilt and requalified before
any new formulation result was opened. P--GRB binding is now provided by one
reusable fingerprint pipeline covering the input and executable hashes,
native fingerprint, canonical LP, objective section, and native variable/domain
identity.
