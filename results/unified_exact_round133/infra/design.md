# Finite execution and future evidence adapter

These scripts prepare execution; no native process or compilation was invoked
by their author. The current source/build/admission gates remain mandatory.

`round133_common.metered(label,kind,argv,reservation,timeout)` counts one outer
process, with C7200/D18000/E1800/D3 7200/repair5400 and total39600 seconds.
E's earlier exact-arithmetic receipt is explicitly included once. An existing
label cannot relaunch; a missing receipt blocks later admission until the actual
PID/Windows FILETIME/argv and outcome have been resolved. Timeouts may terminate
only the owned process tree after a creation-identity check. `light_status` reads
small PID/receipt metadata; it does not decode scientific result files.

The campaign preparer reads the fixed old argv object at its pinned commit,
checks its byte hash and arm index, and adapts only the new PE identity and own
output paths. Each raw directory lives inside a single new campaign identity
under results/unified_exact_round133/campaign so the established portable reader
requires no unsupported external-path fallback. A P/PS canonical reference is
copied only from its exact preexisting reference bytes and must still match the
actual current loaded compact matrix. No reference Optimize is introduced.

The R90/R115/R130 supervisor and R121 producer boundary are reused. They retain
the original complete own wall cap, shutdown reserve, single CPU affinity,
physical check, H/Start costs, native process observation and immutable seal.
Each declared position has a separate own process/identity. Verification starts
after the producer exits and writes an explicit non-native cost segment. A
failed/interrupted or already sealed position is never automatically repeated.

The pure future reader reuses R111 actual model/A-B/scope checks, R118 per-call
log views, R114 return/cleanup checks, R99 full native Start vectors, the R112
24+1 H reconstruction and the R108 complete mathematical cover. It explicitly
checks all ten requested/read-back settings including MIPFocus/Cuts and nested
expected values, with the actual Seed, rather than treating the old Seed0 guard
as the future predicate. Old E3's Seed1 metadata is qualified only after actual
old model/parameter/return checks, and its raw flag stays unchanged.

Schema1 remains the envelope, but the new identity policy marker and event
semantics are checked explicitly. `returned` means the Optimize API returned;
quality, independently checked final routes/bounds and source rejection may
follow before producer sealing. Native MIPSOL witnesses must precede returned;
a postreturn bound follows quality and precedes the next call. The pure
`validate_event_lifecycle` API is the bounded D2 interruption/order fixture
entry. `_journal` additionally checks each original commit/byte identity,
continuous sequence, parameter profile, actual model and physical witness.
Unknown event kinds fail. A missing quality tail or actual native disposition
fails rather than being interpreted as a completed run.

Only in-memory bookkeeping is adapted for old proof components: their historic
integer-precondition Boolean identifies LP versus MIP, whereas the new producer
can qualify an LP's local scope without integer premises. Original payloads are
retained. A qualified returned proof is assigned to the end of its completed
postreturn evidence tail; the real Optimize-return sequence is separately kept.
This prevents backdating final readbacks/quality to the API-return event.

Raw bounds remain available for same-domain contradiction detection. The domain
test does not expand interval or cutoff membership by the objective margin.
Local qualified observations can support their local proofs even without a
complete global cover. Global closure still requires the original complete
cover and provenance checks. Ordinary native OPTIMAL with an excessive signed
physical gap is qualified-open, with T_cert null. No bound/gap clipping occurs.

The new local_bound field is the unconditioned regional value min(raw,cutoff)
for an interval source, after testing raw against every same-domain physical
witness. Raw finite native values use abs(value)<1e100 throughout the new reader;
the Gurobi infinity sentinel is unavailable, not an ordinary bound repaired by
min(cutoff,raw). The reused returned-bound helpers' old 1e90 screening is replaced
only in this new reader context. Original helper files and raw values remain.
The new strict global-bound helper also checks witness membership without
expanding interval/cutoff domains by the objective tolerance.

Each native INFEASIBLE status/event is independently checked against all same-run
physical witnesses, including the sealed own return. A finite cutoff-complement
floor does not qualify an infeasibility claim contradicted by such a witness.
Known ConstrVio/BoundVio/IntVio and LP DualVio values are independently checked
against the registered unchanged residual limits when solution_count>0. Unknown
attributes remain explicit; those tolerance checks are not objective-error
bounds. A known failure must have the corresponding producer source rejection.
The actual solution-count readback return code is mandatory. A nonzero read
code must retain solution_count=null and independently requires the producer's
`native_quality_insufficient:solution_count_unknown;` rejection. The six quality
attribute values/nulls are still retained. Unknown count is never replaced by
zero to bypass LP dual-quality checks or qualify a source.
Native status likewise retains its actual readback return code: failure leaves
the status null and requires `native_status_unknown`. The registered Gurobi13
qualified statuses are 2,3,7..11,15..17. NUMERIC12, SUBOPTIMAL13, and other
unsupported/ambiguous statuses require `native_status_unqualified`. A nonzero
actual Optimize return requires `optimize_return_unqualified`. These checks
revoke the native source even if its raw scalar bound is finite; ordinary
resource-limit open outcomes retain their declared qualification path.

An explicit source rejection is separate. Every native dependent proof is
abandoned; a tree arm must retain exactly R133_FULL_DOMAIN_OPEN with [0,gmax],
lower/base bound0, statusOpen and no closure, plus the abandoned-state record
and explicit controller revocation event. Own feasible U and the independent
nonnegative floor remain. Its implementation failure handling may qualify, but
native proof/performance eligibility and certification remain false. An own
zero is recorded separately. If an independently checked own contradiction was
not identified by the producer, qualification fails.

The abandoned-state CSV must have its exact header, at least one old leaf,
complete field counts and final newline, unique old leaf IDs, finite original
G domains within [0,gmax], numeric claimed bounds (positive infinity only for
an old empty leaf), recognized statuses and the actual nonempty source-revocation
reason. A missing/truncated record or producer-reported write failure blocks
evidence qualification. The verification-failure receipt still retains the
independent own physical U, analytic floor0 and physical evidence; missing
abandonment bytes do not erase a correctly obtained feasible solution. Failed
postproduction audits retain their separately measured non-native costs.

The old tree lifecycle Boolean includes `!hard_failure`; source abandonment
therefore leaves that raw flag false. The rejection branch separately requires
the complete returned-call chain and original optimize/LP/MIP, model read/free,
environment free, restore and reuse identities. It never converts that raw
false flag into a native proof claim. Final raw result.gap is a relative value;
the new scientific endpoint separately retains signed absolute U-L.

The final small endpoint is bound to its full audit/closeout/clock receipts.
`rebuild` aggregates these sealed endpoints and the inherited certification-first
typed comparisons only after production. It is not a polling tool and does not
silently treat raw source rejection as ordinary both-open censoring.

The candidate additionally binds both actual no-improver row emitters and checks
that neither source still calls the old proof-only guard. Actual constant
infeasibility rows are retained: a genuine inventory-domain empty row is not
blanket-banned. For the fixed old E3 D3 positions only, a weighted penalty-floor
row immediately followed by `0<=-1`, with the bound old source and satisfied
original 1e-9 guard, is diagnosed separately as an old model-scope shortcut.
Exact arithmetic records a loaded-inventory-box penalty-floor diagnostic, its
G-floor/cutoff-complement algebra, loaded-RHS rounding difference and distance
to the original 1e-7 contract. This reader has not independently proved that
the loaded local box contains every original physical point, so the diagnostic
is not a qualified physical floor or an old analytic certificate upgrade.
The only approved conservative path is an explicit UNEVALUABLE/model-scope
disposition retaining raw tuple, producer clock and own physical U/floor0,
rather than a numerical native source counterexample. It completes the full
producer/model/scope/return/Start/H/physical/clock audit before setting
evidence_complete=true. Implementation/model-scope/native/performance/certificate
qualification remains false and T_cert null. Other sources keep their normal
checks; only the identified marker's infeasibility claim is classified as this
model-scope issue. This path requires review/legacy_shortcut_reader_admission.json
with decision ACCEPT, the final reader_SHA, and policy
OLD_D3_MARKER_UNEVALUABLE_AFTER_COMPLETE_AUDIT. D3 admission checks it before
any native launch, and aggregation checks it again. No other old qualification
compatibility or analytic upgrade is enabled.
