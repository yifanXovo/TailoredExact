## Concrete blockers in inspected source

1. **Solve results lack the inherited numerical admission checks.** `Round105GurobiDecomposition.inc:71–96` logs status/bounds/objective but does not check per-model parameter readback, native ConstrVio/BoundVio/IntVio, numerical-trouble/unscaled-violation warnings, or actual returned full-X row residuals. Preserve actual original defaults (the inherited helper checks FeasibilityTol=1e-6, IntFeasTol=1e-5, OptimalityTol=1e-6); do not tune them. Apply accepted status/quality/log contracts before bounds, infeasibility and certification; check actual incumbent bounds/integrality/all rows when one exists. Infeasible solves have no incumbent quality attributes, so absence is not itself failure, but their status/log/model/assumption scope must be preserved. A physical witness can establish FEASIBLE independently of shortest-route optimality.

2. **Startup isolation has hidden routes for imported or changed information.** Main's guard at `src/main.cpp:3379–3393` rejects explicit external incumbent paths but permits `incumbent_archive_auto=true` (historical archive scan at `:12674`) and `gcap_seed_cplex=true` (`:13136`). These violate the requested self-paid unchanged ENS startup. Explicit heuristic/settings overrides can also change the inherited 24+1/R76/R83 policy while retaining the same preset name. Reject incompatible overrides or freeze and check the complete intended startup contract. `route_pool_incumbent=true` is already the inherited default; preserve its established policy rather than blanket-disabling it to fix isolation.

3. **Error exit can erase durable valid-state reporting.** Contract/API/mapping/persistence exceptions after an accepted bound escape `r105Solve`; local LB/UB, stop reason and summary are not durably finalized. The existing calls/pattern files may survive, but no result/summary preserves the strongest accepted LB and strict physical UB with an ERROR classification. Add an error boundary that returns/saves the retained genuine evidence with strict certificate false. Do not treat errors as infeasibility, silently fall back to ENS, or manufacture a certified status. Persist after-call failure closure as well as before-call records. Some evidence streams (`variables`, `embedding`, `patterns`, `conflicts`, IIS proposal) are written without a final success check in this snapshot; persistence failure must not pass audit admission.

4. **The executed loop qualification never learns a cut.** `qualification/native01/loop/round105/summary.json` reports one iteration, one master/oracle solve, U0=1.1, LB=UB=0, conflicts=0. Therefore `tests/round105_tests.cpp` validates direct all-feasible closure but not the addconflict/update/reoptimize path or full-vs-core loop equivalence. Add an end-to-end fixture that requires a proved infeasible master candidate, a recorded violated valid row, a distinct subsequent candidate and correct final bound/witness; require observed conflicts instead of merely checking eventual certification. Real nonempty integer master modes and a proved real failure/core remain required before performance admission.

5. **Sparse startup route records can fail before normalization.** `r105Solve:184` applies the strict complete witness wrapper to unmodified `seed.routes`, while main `acceptIncumbentRoutes` at `:12382` copies the candidate route list directly. If the unchanged ENS startup omits an unused vehicle, the strict wrapper rejects before `normalizeRound61Routes` at `:229`. Normalize/pad the full physical list explicitly, reject duplicate vehicle/station/operation records, then create the sparse canonical-mapper representation separately. Ensure the final returned initial UB retains a complete strict witness. Main's original empty initialization is complete, so this is a boundary case rather than evidence that current role startups all fail.

These blockers do not imply a counterexample to the route MILP or conflict algebra. They prevent promotion from a source prototype to qualified formal evidence. No performance conclusion follows from them.

## Mathematical implementation checks that pass statically

**Master transformation.** `r105Solve:201–227` explicitly looks up every x column as binary and load column as integer, changes only those indices to C, requires z/m B, p/d/Y I, state B and ord C, and reads back unchanged names/bounds/types. This is not blind prefix relaxation. F0 conn is already continuous and is not falsely listed as newly relaxed. All state selectors remain binary, which is necessary for exact G*Y under integer stocks. No coefficient/row mutation precedes seed mapping; type relaxation preserves every original physical projection.

Root spec at `:188–194` uses a=0, b=min(1,U0), non-strict cutoff U0 and epsilon=0, single VD-P root with F0 policy, no AM. b is wider than the suggested min(U0,(n-1)/n), but still contains the entire relevant true-Gini range and is safe. The same verified U0 drives all derived domains; no leaf/cutoff/historical resource evidence is imported. Full all-column mapper values are checked against every actual master row at `:228–240` before Start insertion. The inherited strengthened master metric restriction still applies; oracle generality does not extend it.

**Objective and integer mode extraction.** Preserved one-hot binary states give state_g=G*s and zprod=G*Y; G and absolute-value auxiliaries remain epigraph variables. With S>0, model objective >= true F(Y); S=0 can choose G=0 in this root. Every original solution with F<=U0 embeds at true F. Extraction at `:262–283` checks integral Y, selected state, z/p/d/m, nonzero one-way quantity, unique service and exact b-Y. It compares true F to master ObjVal and stops on mismatch. Thus it does not manufacture a UB from the master objective. At a verified all-feasible optimal candidate, reverse physical embedding and epigraph domination close the objective. The equality check before routing is conservative if an artificial infeasible mode could only appear with an inflated epigraph; it is a stop/investigation, not an unsafe exclusion.

**Universal single-car oracle.** `Round105Decomposition.cpp:59–139` includes all original stations and all directed original arcs, local binary z/m/x, integer p/d, continuous load/order, one-direction nonzero service and full local domains. Every candidate-specific condition is a named assumption row; generic bounds/physical rows are independent of candidate operation values. The objective is zero, with no Gini/fleet cutoff/other-car obligations. Fixed full assumptions force both service and absent stations correctly. Deleted core assumptions truly restore all their local station/arcs/quantity possibilities.

Degrees give each visited station one incoming/outgoing arc; depot balanced degree <=1 and MTZ exclude disconnected cycles. The actual MTZ is u_i-u_j+(V+1)x_ij<=V, with z_i<=u_i<=V*z_i. Active arcs increase order by one; inactive arcs are harmless since u_i-u_j<=V. Every simple legal route embeds by its position. Load inequalities use both signs and M=2Q; inactive expressions L_j-L_i-p_j+d_j lie in [-2Q,2Q], active arcs impose exact prefix recurrence, and depot-start recurrence sets incoming load zero. Continuous load is exact on binary routes with integer fixed operations. No <=Q condition is imposed on cumulative pickup; return load may be positive. Duration is original travel+(cp+cd)*total pickup, including final depot unload. Local station capacity follows direction/p/d caps. Therefore the generic/full-assumption model is bidirectionally equivalent to the specified single-car physical domain, subject to the numerical contract and valid inputs.
