## 唯一统一正式行候选及证明合同（尚未准入实现）

对每车 k，令 `a_k=Σ_{j≥1}x_{k,0,j}`、`P_k=Σ_{i≥1}p_{ki}`、`c=t_pick+t_drop>0`。从该车**实际导出**的 duration 行读取同一 T、每个 pickup 的同一正系数 c、每条允许有向弧的非负旅行系数 d_ij；在这些弧上精确求 `ℓ_min=min_i[d*(0,i)+d*(i,0)]`，最小值覆盖所有可访问站点。定义 `B=max(0,⌊(T−ℓ_min)/c⌋)`，仅加统一行

`P_k ≤ B a_k`。

整数有效性：depot 出入平衡使 `a_k∈{0,1}`；F0 连通、访问流和 `p_ki≤pmax_i z_ki` 保证 `a_k=0⇒P_k=0`。若 `a_k=1`，闭合非空路线至少到达一站，非负有向弧使其旅行 ≥ 该站的去返最短路之和 ≥ ℓ_min；原时长行遂给 `cP_k≤T−ℓ_min`。`P_k` 是整数，故 `P_k≤B`。空车/空路线 `a=P=0` 有效；载货返库的卸货计入当前模型的 drop 处理时长，处理总量仍为 `cP_k`，不能偷换成 `P_k≤Q_k`。`S=0` 的 Gini 零分母约定与此行无关，零服务时也满足该行。若 `T<ℓ_min`，原模型没有可用的已启动车路，B=0 行仍有效但不表达更强的 `a=0`；若 `c=0` 或 c 非正/不统一、允许负有向弧、服务可脱离 depot/F0，须停用此构造。无需 metric；不能在没有独立 metric 证明时用直接 depot 边代替有向最短路。

在**隔离的聚合整数块** `{(0,0)}∪{(1,p):p=0,…,B}` 中，该行与 `0≤a≤1, P≥0` 恰给其凸包：`(a,P)=a(1,P/a)+(1−a)(0,0)`，而 `[0,B]` 是整数 `p=0,…,B` 的凸包（a=0 单独处理）。这只说明该二维块的启用取整凸化；若实际车路约束另排除部分 `p` 或 `T<ℓ_min`，更不能据此称完整路由/库存模型凸包。B 的整数有效性是一般取整原理在本模型上的应用，不能主张新颖性。

未来任何正式实现必须逐行审计原 depot、访问/F0、pickup 域和 duration 行，按 readback binary64 系数视作精确 dyadic 求有向最短路与 `floor`；若改用浮点区间，只可向下包围旅行/ℓ_min、向上包围 T、向下包围 c，再对商取**安全上界**的 floor。绝不能因最近整数、输入坐标或向上旅行舍入而缩小 B；B 超出可精确导出的整数系数范围或变量/行身份不符就 fail closed。新增行的 solver readback、原行/目标/cutoff/G 域、原数值容差和物理 verifier 均需保持；若用动态分离，活动判断还需保守误差余量。R7/R8 已用路线掩码/循环旅行下界，R63 有相近的连续旅行启用行但未取整，历史根界收益未带来稳定 MIP 收益；本行不能被描述为首次提出。
