# Portable checker source-only pre-review

This is a static review while D1 native execution remains active. No project
import, fixture, meter, model/H parsing, reconstruction, compilation, packing,
PDF export or recovery has been run by this reviewer. Runtime acceptance is
pending completion of all native work and the primary agent's controlled run.

The proposed checker retains the fixed22 formal positions and separate one
unit position. Unit eligibility is explicitly excluded from formal/performance
denominators. It loads exact helper bytes from the published helper carrier,
the109 source/header bytes plus generated source from the candidate carrier,
and both reused main source/binding pairs. Old Git lookups resolve only named
published code dependencies; no Git process or old-checkout lookup is allowed.
The draft publication producer now includes the reused main bytes identified
as a required new dependency during the handoff repair review.

PE, DLL, main-object and archive digests are explicitly historical execution
attestations. They are not opened or remeasured in recovery, and the report
does not claim otherwise. The scientific files still require actual bytes.
Path transport maps only the declared measured root into the new root;
unknown external paths fail, and symlink escape is rejected. Native-asset
attestation is not a substitute for model, log, H, Start or physical data.

The verifier clone has five explicit one-occurrence substitutions: recognize
an already measured closeout, use its independently checked verified clock
values, and report new replay wall separately. These changes do not remove a
source, scope, physical, model, H, Start, return or cover predicate. A formal
arm invokes the actual8feae adapter's postseal H/PS context and first checks
its effective policy receipt/four output hashes. The unit uses its actual933
policy. Derived JSON writes are confined to a named in-memory overlay; stored
bytes remain the comparison input. Normalization is limited to root paths,
derived-hash links and the one independent H replay-time field. Measured
production/verification clocks remain numeric and are checked before replay.
