# Round152 finite evidence and recovery

The [source manifest](source_manifest.json) binds final research source bytes,
the unchanged production source/PE/DLL and the fixed R151 dependency base.
Per-process source snapshots and content-addressed source copies preserve
the versions used after snapshot recording began. The disclosed earlier runs
retain actual admitted matrices, points, rows and failed source copies;
final source is not substituted for an earlier performance identity.

The [reuse index](reuse_index.json) resolves inherited members by immutable
commit, archive/member path and SHA256. Original B roots and the matching
K35 AP result are reused after semantic validation. Old large archives are
not repacked, and recovery never invokes their historical producers.

Four new carriers contain the three real-domain studies and the small-domain,
qualification, failure, fee and source-snapshot evidence. Thin reports,
mathematical analysis, reviews and source files are separately versioned.
`carrier_manifest.json` and `public_manifest.json` record archive, part,
member-index and thin-file hashes; compressed member indices record every
archived byte stream. Archives larger than 40 MiB use 32 MiB transport parts.
PE/DLL, credentials, compiled files and old archives are not carriers.

After ordinary commit and push, `scripts/round152_delivery.py restore COMMIT`
downloads the fixed new public manifest, every new thin file and carrier from
anonymous raw GitHub URLs into a new empty directory under
`E:\codes\ExactEBRP-work\restore`. It verifies file and reconstructed archive
hashes, checks every member hash and safely extracts all new evidence. This
is one finite byte recovery, with bounded HTTP retries. It performs no Native
call, Optimize, compilation or old producer invocation. Old fixed references
remain in the reuse index; their already accepted historical recovery is not
repeated. The actual `public_restore_receipt.json` is delivered afterward.

This is a finite scientific record, not a promise to rerun all historical
experiments. The saved Native call/return journals, full matrices, solutions,
pricing brackets, domain scopes and fees are the primary evidence. The main
and independent audits already verified decisive matrix/point/dual relations,
all new call returns, all recorded true-stock upper bounds and source identity.

The final [RESUME](RESUME.md) records the science commit, Draft PR and cleanup
receipts. Delivery-only records are intentionally outside the fixed public
manifest to avoid a self-referential commit/hash dependency. No new production
candidate/profile exists; complete BRP performance for this mechanism remains
unobserved.
