## Problem and proposed change

The fixed Round91 canonical-LP diagnostic found a processing-capacity relaxation gap on C2: its numerical original-F bound rose from 0.60266647 to 0.62264258 with two rounded travel/activation rows. D3 showed no objective gain. This PR implements and tests one uniform static row family. The full-method screen now shows why root-bound improvement is insufficient: the candidate improves D7's censored endpoint but triggers the preregistered U6 gap-risk stop and is not promoted.

For each vehicle, the proposed row bounds total integer pickup by a proved processing allowance times binary depot activation. The first implementation used the emitted canonical duration coefficients. The reviewed repair uses one lower coefficient system shared by raw physical and emitted data, one directed shortest-route computation, and an outward upper horizon covering the unchanged physical acceptance rule. Rounding the quotient upper bound down gives a conservative integer row without a new tuning parameter. The design covers zero handling, no closed route, loaded return, coefficient serialization and unsupported arithmetic.
