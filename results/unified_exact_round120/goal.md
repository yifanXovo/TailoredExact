## 3. 不变物理问题与证明对象

对服务站 i=1..V（排除 depot0）：

\[
Y_i=b_i+\sum_k(d_{ki}-p_{ki}),\quad r_i=Y_i/D_i,\quad
F(Y)=G_{\rm true}(Y)+\lambda\sum_i\omega_i|r_i-1|.
\]

沿原 S=0 约定、权重、空载出发、一次一车非零单向整数服务、0≤Y≤C、全部载荷前缀及返仓载荷在[0,Q]、允许带载返仓。完整路线时长为 travel+(pickup_seconds+drop_seconds)×累计pickup；旅行使用原 Parser 的 Euclidean/1.5。Q 不限制累计pickup；min_ratio 不形成新库存下界。

保留 M-B 的 p/d 连续声明、整数 Y/load、二元 s/z/m 及原 A/B；不启用独立 ENS-Q。H 保持原 Seed20260626、24+1 及当前完整 closure/exchange；所有方法自付费生成，不导入 R119 解。

设原根实际区间为 I=[a,b]，实际中点为 m。原控制器已经付费并成功返回 I0=[a,m]、I1=[m,b] 的两个证明 Cj。Cj 必须支持：

\[
x\in\mathcal F,\quad G_{\rm true}(x)\in I_j,\quad F(x)\le c_j
\quad\Longrightarrow\quad F(x)\ge\ell_j.
\]

旧 cutoff 外的补集给出物理区间下界

\[
\beta_j=\min\{\ell_j,c_j\}.
\]

这是理论表达；生产使用当前数值合同下保守的 \(\underline\beta_j\le\beta_j\)：明确沿原 1e-7 证据安全余量作向下处理，并对实际序列化系数作保守舍入。该余量不可调参。不能只向下取一个 ULP 就把求解器数值界说成有理证书，也不能悄改原 1e-7 最终认证政策。对非负目标可使用已证明的0作更弱回退；有真实来源矛盾时，回退0不能修复已经基于坏证明执行的搜索。

首版仅接受既有、完整返回且通过原标准的有限 OPTIMAL 根子 LP 证明；UNKNOWN、打印末值、可行目标、局部 node bound 不得使用。原不可行半区处理照旧，本轮不增加新的 infeasible 证明变种。

## 4. 唯一候选：一个选择器、三条静态原生行

以下公式用 β 表示已经合格并保守存储的下界。记 f(x) 为原生模型在原目标尺度上的完整线性目标表达式，包含实际常数项，而非任意 surrogate 或截断目标。

新增二元变量 h∈{0,1}：

\[
\boxed{
\begin{aligned}
g&\ge a+(m-a)h,\\
g&\le m+(b-m)h,\\
f(x)&\ge\beta_0+(\beta_1-\beta_0)h.
\end{aligned}}
\]

h=0 对应左闭区间，h=1 对应右闭区间；共享中点允许重叠，不用 epsilon 制造互斥缝隙。不假设右侧界更强。全部系数来自本臂自己的输入与已支付证明，无任意大 M、触发秒数或实例常数。

实际写入的差分系数也必须检查：下界链接在 h=0/1 的右端不得分别高于 a/m，上界链接的右端不得分别低于 m/b；目标下界行在 h=0/1 的右端不得分别高于已合格的 β0/β1。用真实序列化系数及精确有理读回或等价保守运算审查这些端点，不能只验证各常数分别向下取整而忽略差分再相加的舍入。允许保守的端点外扩，但不得向内制造缝隙；记录实际模型与理论精确区间的区别。

候选暂名 **MB-D1**。本轮只使用初始根的这一对证明，一次登记，数值与原作用域此后不可被新 incumbent 覆写。不增加每个后代的新选择器，不枚举多个分点，不使用“最佳一对”筛选。

证明至少包含：

1. 每个原根域中的物理可行解，选择 g=G_true 并按所属半区赋 h，能扩展到原 VD-P/F0 表示并满足三条行，目标保持 F。结合原根 cutoff 补集，所有严格改进解仍被覆盖。
2. 新模型只收紧原模型；原整数模型到物理可行解的映射和 f≥F 条件仍成立，因此没有把新模型目标当成未经验证的 UB。
3. 理论上，在 f≤u<β1 的改进域中 h=1 不可行，故 g≤m；左右对称。该逻辑不保证 Gurobi 在何时传播或分支，也不能假定“物理 own U 更新”已经成为原生 incumbent/cutoff。记录可核对的 native objective 与 physical F，分别说明。
4. 根证明只能用于它包含的后续域。若原 M-B 自身建立了后代 MIP，可以携带同一根三行与一个选择器；必须核对作用域包含和原嵌入，不把子模型高界反用于父域。
5. 证明依赖有数值反例时，新行及所有依赖 native bound/closure 都失格。合法 own fleet 不恢复失效的精确性。

当 β1≥β0 时，把 h 放松到[0,1]，仅在标量(g,f)空间投影得到：

\[
f\ge\beta_0,\qquad
f\ge\beta_0+\frac{\beta_1-\beta_0}{b-m}(g-m).
\]

这是两个“区间+目标下界”集合的凸包下包络，不是完整 BRP 整数凸包，也不复制完整 child F0 的强度。另推 β0>β1 的对称情形。分母只用于数学解释；生产三条行没有这项除法。根 LP 不必因此明显改善，额外二元也可能干扰整数搜索。

### 必须处理 model g 与真实 G

原 g 是上图变量，不在每个整数模型点都等于 G_true。上述证明允许通过 g=G_true 的目标保持嵌入保留每个原物理解；它并不自动证明不会删去原模型中某种虚高 g 的整数辅助变量补全。

因此首版是在 Optimize 前构建一个经原问题投影等价性核验的扩展 formulation，不是把物理剪枝结论直接当作 `GRBcbcut` 的全局 user cut。尤其不能在 incumbent 越界时向 callback 塞 g≤m：该行可能删去仍合法但较差的整数解。也不要改为 lazy constraint 以规避这一义务。

## 13. 唯一阶段出口

- `ADVANCE_NATIVE_PROOF_DISJUNCTION_TO_CONFIRMATION`：核心准入与N40完整跟进均完成；D1保留至少一项对M-B的材料性完整收益，并有D1/D0有限条件信息证据；跟进无严重P回退，证书能力未被未补偿损失破坏。只支持后续固定确认，不更改默认。
- `RETAIN_NATIVE_ENCODING_WITHOUT_CONDITIONAL_ATTRIBUTION`：完整方法有有限正信号，但条件行贡献或风险交换未解决；保留结构和限制，不自动选择D0或扩大测试。
- `STOP_TESTED_NATIVE_DISJUNCTION`：真实曝光但完整表现不支持或核心准入失败。保留正例，关闭本配置，不自动加priority、cutoff阈值、完整child hull或其它机制。
- `STOP_NO_NEW_RELAXATION_INFORMATION`：第8节在两个完整真实LP上可靠证明没有新增放松信息；不把未解诊断当该结论。
- `DO_NOT_REOPEN_EQUIVALENT_CONFIGURATION`：定向历史证明已有同等配置和充分适用结论，无真实新增能力。
- `BLOCKED`：原问题嵌入、数值证据、安装/Start、资源或必要输出等真实障碍使既定阶段无法合格完成。普通LOSS、没有显著收益、所有方法开放不是BLOCKED。

阶段决定按如下优先顺序唯一化：真实正确性/必要证据障碍先 BLOCKED（并标相应证明风险）；前置等价或完整LP无增量分别沿对应 STOP；已完成性能中若出现严重P风险或未补偿认证损失，选择 STOP_TESTED_NATIVE_DISJUNCTION。若无这些风险且完整方法有正信号、但仅条件归因准入未满足，选择 RETAIN_NATIVE_ENCODING_WITHOUT_CONDITIONAL_ATTRIBUTION；没有完整方法正信号则 STOP。只有全部核心准入及N40跟进兑现且满足上述推进条件，才选择 ADVANCE。不得同时输出两个阶段标签。
