# Round107: ENS complete-cover assignment events

This experiment asks whether the original ENS-C outer search restores certification and improves conversion of inventory/attribution candidates into good physical fleets when its integer route interface uses the qualified R106 STRUCT decomposition. GLOBAL-STRUCT is the inherited R106 global assignment event method. FRONTIER-STRUCT keeps the ENS controller and its corresponding domains. The comparison is not a complete 2x2 factor experiment and does not identify the effect of one AM parameter or native search strategy.

The physical problem, parser, metric domain, numerical tolerances and evaluator are unchanged. Inventory is `Y_i=b_i+sum_k(d_ki-p_ki)`, ratios are `Y_i/D_i`, and `F=Gtrue+lambda sum_i omega_i |r_i-1|`. Positive-denominator Gini is `sum_(i<j)|r_i-r_j|/(n sum_i r_i)`; at zero denominator the inherited evaluator uses G=0 and keeps the penalty. Empty initial vehicle loads, every prefix and return load in [0,Q], one nonzero one-direction integer service per station, and closed routes remain mandatory. Loaded return is permitted. Handling is `(pickup_seconds+drop_seconds)*sum pickup`, including return unload. Cumulative pickup can exceed Q after intermediate delivery.

Every integer request reads the original immutable VD-P canonical model. Only x binary and load integer types become continuous. Y/state/z/mode/p/d retain their integer declarations; every row, bound, objective coefficient, constant and all original continuous columns are retained. Selector completeness and the exact selector sum/inventory reconstruction equalities are checked against actual current Y bounds. LP and child LP requests delegate to the original all-continuous backend. They receive no learned rows or physical oracle calls and require no additional Optimize.

Let O(I,c) be the original physical solutions whose true G belongs to the actual request interval and whose F satisfies its actual objective row if present. The original factory omits that objective row at nonpositive cutoff or lambda <=1e-12. The request's improving-domain interpretation may be narrower than an actually exported relaxation; this only weakens its lower bound. Let R(I,c) be the retained canonical model with x/load declarations relaxed and globally proved physical rows enforced lazily. Scope metadata records canonical SHA, exact I, actual cutoff RHS/epsilon or absence, epoch, call category and original mathematical target. It never substitutes the R106 U0 root for a leaf.

For any original solution in O, use its actual route arcs, prefix/return loads, operations, inventory selectors and exact objective auxiliaries. All original necessary rows are valid, route relaxation includes the original declarations, and globally proved conflicts preserve that solution. Thus O embeds in R. Every qualified native master bound is a bound for this local original domain. Empty O is a legitimate special case. A global incumbent need not lie in I or a strict improvement domain, so absence of a Start does not invalidate a leaf.

At an integer master candidate, the retained service mapping gives exact Y and unique operations. The canonical epigraph objective can exceed true F, including when true G is below the interval's lower bound. Its objective cannot fall below true F beyond the original tolerance. Exact raw vectors, objective dot products, integer/bound/base-row residuals and Y/operation relations are audited. A violation makes that request ERROR, strips every new bound/target/terminal bit, and stops the solve. A separately verified physical UB is retained.

The separator is the unchanged deterministic R106 STRUCT: scan all cars for conservative A and balanced rank-3 B; reject on a reliably violated proved row; otherwise FULL-oracle cars in fixed order. A keeps the conservative MST/handling assumptions and only transfers across compatible physical parameters. B retains the complete six orders, strict extra-pickup budget and ownership/threshold preconditions. FULL proves infeasibility of the complete operation pattern in an independent optional-station physical model. If a helper is not fixed away it remains available in the template; no failed partial pattern alone excludes all extensions or a whole Y. No IIS/core or new net-return inequality is used.

FEAS, INF and semantic row evidence belong to one self-paid run. Pattern keys bind all operations, vehicle Q, physical T, handling, travel and numerical assumptions. UNKNOWN is never an INF cache entry. Full semantic coefficients are saved before local remapping, with the first proof path and originating request. A selector absent in the current model can be omitted only when its value is outside the checked current integer Y/selector domain; an absent in-range selector is ERROR. Expanded domains remap the original complete row, rather than reusing a truncated old row or old column number. The pool is only a lazy-candidate pool, never an LP/static-row strengthening.

A current violated valid lazy row rejects a raw point; previous API0 does not substitute for current rejection. Repeats can be resubmitted without an arbitrary repeat limit. Arithmetic certificate emission, first semantic row, cache/cross-request hit, remapping and actual lazy API submission are distinct counts. A/B/FULL inequalities and FEAS routes are independent of Gini/cutoff and can cross requests; a local INF/optimality/bound conclusion cannot.

Only all-car physical validation creates a global own UB. The full mapper separately tests true-G/cutoff membership, every column, objective and current base/proved rows before Start or feedback. A verified outside-domain witness records a skipped injection and remains a global UB. Any other mapping or residual failure is ERROR. A mathematically audited embedding is retained even if cbsolution is deferred; subsequent native INF would contradict that embedded witness. API attempts, deferred responses, exact later vector observation, final native acceptance and external physical UB are separate facts.

Reliable INFEASIBLE closes only the current improvement domain. INF_OR_UNBD, no incumbent, ordinary interruption and UNKNOWN do not prove emptiness. Reliable OPTIMAL closes only after the final accepted service mode is physically verified and its qualified local LB dominates own global UB under the original tolerance. That is bound dominance, not a claim that the physical UB attains the true optimum inside I. If OPTIMAL lacks closure, the whole solve stops with an open obligation. A local LB above global UB is ordinary valid dominance, not a contradiction and not a global bound.

The ENS scheduler alone aggregates the complete initial cover and all open/replaced/closed obligations. Since F>=G and G<=gmax, its original coverage of improving G values suffices. Shared boundary overlap at midpoint preserves coverage. A local high bound or empty leaf cannot close another unresolved leaf. Tightening the own cutoff creates a subset improving domain; old valid bounds/exclusions inherit, while original canonical/LP/child identities invalidate by epoch. A single oracle objective, candidate objective, leaf OPTIMAL or partial target never yields a global certificate. Zero objective uses the inherited valid nonnegative global bound.

Partial MIP termination uses only a qualified native bound reaching the original AM/frontier target. Target success updates that obligation and follows the original requeue/milestone rules; it does not imply local or global optimality. An unrejected UNKNOWN outranks target success and stops the whole solve, preserving open coverage and only already-qualified pre-stop bounds. Delivered MIPSOL after cancellation is still saved/base/objective audited, then conservatively unresolved; it starts no new inner Optimize. Bounds freeze after UNKNOWN, and final suspect native attributes are excluded. ERROR removes all newly generated proof from that request.

Every MIP uses one native Optimize with MIPSOL/lazy processing and separate inner environment/model. The outer waits for the single-thread inner oracle. Fresh model reads between ENS requests are explicitly counted; there is no candidate restart, preserved native tree or claimed basis continuation. The original 24+1 startup and physical exchange closure are self-paid once per arm, under one deadline beginning before startup. Final remaining time is checked after ahead-of-call/journal writes; canceled intents are marked not started and are not paid Optimize. All actually created/read/freed resources and started calls survive failed finalization via operation observers.

The R92 conditional finiteness premise remains finite accepted LP/native returns or whole-run stop. Finite integer inventories give finitely many distinct physical objectives and improving epochs. Finite depth/width geometry gives a finite tree. Same-epoch child targets and identities remain cached, the frontier milestone remains once-only, and each same-epoch leaf has the original single terminal obligation. Accepted target transitions therefore proceed to split or terminal rather than an unlimited refresh/requeue loop. Native OPTIMAL without closure and unrejected UNKNOWN stop the algorithm. This is a conditional controller progress statement under the floating-point engineering contracts, not a bound on native runtime.

New native qualification distinguishes terminal closure, strict-empty INF without Start, out-of-domain global UB/high local LB, actual shared FEAS/FULL cache and row remapping, and actual target -> native interrupt -> original controller requeue -> terminal -> complete-cover certification. Deadline qualification includes a production outer request and an isolated actual FULL invocation with the same inner cancellation callback; neither is a performance arm. Pure/scripted scope decisions and inherited A/B physical counterexamples are labeled separately. Formal conclusions require independent admission and complete same-PE four-arm comparisons in both protected roles.
