# Round90 conditional handoff: one LP-G split ablation

Status: source-only preparation after the Round89 D3 preregistered stop. No Round90 branch, implementation, build, test, solver run, or performance admission exists. This selects only the LP-G point proposal accepted in [Round88 split gate review](../unified_exact_round88/split_next_gate_review.md), with the limits proved in the [critical-band note](../unified_exact_round88/split_critical_band_proposal.md).

## Exact proposed behavior

Add one **default-off**, explicitly named research flag (suggested `--round90-lp-g-split true|false`) applicable only to the original Round83 ENS-C first-class K1 controller. With the flag off, leave the frozen 24+1 startup, interval midpoint, model rows, AM score, logs and identity unchanged. Reject the flag with any non-ENS-C preset or Round88 A1/Round89 native-B1 flag; no C1 depth removal, C3 shortcut, Round43–45 envelope/parametric split, new balance threshold, or combined variant.

After a complete optimal parent LP for the **current** canonical model, choose its finite returned `G` as `p` only when `a < p < b` in the actual `double` values of the selected leaf `[a,b]`. Require `state.lp_complete`, `terminal_valid`, `optimal`, `!infeasible`, `round43_lp_g_available`, `lp_incumbent_epoch==incumbent_epoch`, and a ready artifact for the same epoch/leaf model SHA before using the scalar (`src/PaperExternalGiniTree.cpp:3567–3642,4275–4306`; `src/GurobiBaseline.cpp:3303–3349`). If any condition fails, select the **existing** `splitLegacyFrontierInterval(a,b,2)` midpoint. Do not round, clamp, nudge, or impose a distance-to-endpoint threshold on a valid interior `G`. If the resulting two-child geometry is malformed, fail closed rather than accepting a tolerance-sized gap.

For the LP-G choice, construct the closed child domains from the *same stored* `p`: `[a,p]` and `[p,b]`. Explicitly require finite `a,p,b`, exact endpoint equality (`left.lower==a`, `left.upper==right.lower==p`, `right.upper==b`), and strict `a<p<b` before the existing tolerance-based `exactIntervalCoverage` and scheduler transaction. The common boundary intentionally belongs to both children; their union is exactly the parent domain. Existing `exactIntervalCoverage` accepts deviations within a tolerance (`src/GiniFrontierGeometry.cpp:450–479`), so that check alone must not certify exact new geometry. The existing eligibility remains `depth<8 && width>1e-4+1e-12` (`:362–369`): even arbitrarily uneven interior splits have at most eight descendants along a path, and a too-narrow leaf goes through the unchanged exact terminal MIP. The same full left/right child LPs, exact child infeasibility handling, AM `ημ≥0.08` decision, native target/requeue, atomic coverage replacement, global deadline and final proof remain (`src/PaperExternalGiniTree.cpp:6124–6329,6338–6346,6990–7143,8181–8383`). Never infer a child bound from the raw product-row violation at the parent point.

The mathematical reason to inspect this single point is narrow: for the fixed parent LP point, `p=G` maximizes the smaller summed raw product-row violation of the two children. It does **not** ensure an LP-objective gain, eliminate another optimal parent point, or predict MIP speed. D7/F2 historical roots have LP `G` values distinct from their interval midpoints, but their old child LP results cannot be transferred to the new domains.
