# Independent production preflight

Reviewer: `/root/round148_independent_review`, a nonimplementer. This is a
read-only mathematical and control-flow review. It does not replace the actual
arithmetic-driver, writer, Native and Start qualifications before admission.

The finite production slopes are only selection choices. Their validity does
not depend on exact optimality of the long-double breakpoint search. Once each
actual binary64 slope is chosen, every state at that station uses the same
slope. `Interval` addition and four-corner multiplication enclose the exact
results by one outward `nextafter` on the rounded endpoint operation; reciprocal
division requires a positive denominator. Zero identities are exact. The
inherited compiler flags do not enable fast-math or reassociation. Overflow is
rejected by the finite-arithmetic requirement for the current bounded domain.

The lower endpoint of `phi` is at most its exact value. Subtracting the enclosed
product of the actual slope and denominator therefore gives a valid intercept
lower bound at either interval endpoint. The exact kink is enclosed by
`n * (c_i*y)`. If that enclosure overlaps the denominator interval, evaluating
`-b*kink` over its whole enclosure gives a safe lower value at the exact kink;
including an extra node can only weaken a minimum. Thus the minimum of these
lower values is below the exact three-node minimum. Summing the actual slopes
with interval addition encloses the exact beta. The lower endpoint of
`alpha_lower + beta*(c_i*y)` is consequently a valid pure-selector RHS
coefficient. A nonzero tiny coefficient is lowered to `-1e-12`; no negative
coefficient is erased toward zero. Nonnegative selectors make these
componentwise weakenings safe. Both finite moment fallback directions have the
correct sign.

The first normal root LP enables the existing named-primal capture and passes
that outcome directly to `generate`. The selection receipt records the source
call, model SHA, scope, gamma interval, cutoff and point. No historical point or
row is injected. A positive denominator and saved conditional bounds, rather
than a nonempty old-GD row vector, determine eligibility. The algorithm returns
normally without an empty reoptimization when no violated row is selected.

After a selected row is appended, the old backend leaf is discarded; LP
completion, evidence, fingerprint, terminal flags and unused child-cache state
are cleared; the request receives the new immutable artifact and a new log
before one paid root LP is run. Later normal root processing uses that returned
outcome. The original root matrix and log remain. New cutoff epochs and
compatible children embed GD first and then the frozen affine row. Support,
gamma and cutoff checks prohibit inheritance into an expanded domain. The GD
expected vector is copied under the appended model SHA without re-embedding GD,
and both old and new SHA entries remain. The new Native audit checks one exact
expected row in the actual matrix. Main argument restrictions retain isolated
standalone D as the carrier. OFF keeps all new selection/append/reoptimization
paths inactive.

No blocking defect was found in the inspected code. Pending admission checks

fixed/omitted/compatible domains, complete and nonminimal Start, and an actual
