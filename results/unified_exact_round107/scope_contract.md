# Round107 interval scope and result contract

This candidate is default off. The original ENS-C controller owns the complete interval cover, AM decisions, incumbent epochs, child caches, and global certificate. A backend result never becomes a global bound or certificate on its own.

## Actual requests and domains

`PaperExternalGiniTree` writes the original strengthened VD-P/F0 canonical model for each `(leaf, epoch)`. The request identifies its immutable path/SHA/row signature, closed native bounds `gamma_L <= G <= gamma_U`, and the verified cutoff. In the current ENS path `ensureArtifact` explicitly sets incumbent epsilon to zero: the actual objective row is non-strict. Qualification also exercises a finite strict-improvement fixture with a positive epsilon. The adapter reads the actual objective-row RHS and reports `epsilon = verified_cutoff - RHS`; it never replaces the request domain by the R106 root domain. Midpoint children overlap at a boundary, which preserves complete coverage. Scheduler relevance tests use the original certificate tolerance; the native closed interval and the scheduler's improving-domain tests are separate predicates.

`O(I,c)` contains original physical solutions with true G in I and the original request's actual objective restriction `F <= c-epsilon` when that row is present. Its definition is in the original physical problem, not whatever happens to satisfy the exporter. The inherited canonical necessary rows are valid on that original domain, and its actual routes, exact selectors and objective auxiliaries give an embedding. `R(I,c)` retains every canonical row, coefficient, objective, bound and original continuous declaration; it changes only route `x` binaries and `load` integers to continuous, and adds globally proved physical conflicts at reliably violated MIPSOL points. Y, state, ownership, direction, pickup and delivery integer declarations remain.

The original interval row factory activates its objective cutoff only when the verified cutoff is positive and lambda exceeds 1e-12. Absence is explicitly recorded and preserved; no new cutoff or epsilon is invented for zero/lambda-zero cases. If the solver's actual domain is larger than the request's improving domain, the embedding/lower-bound argument is still valid for the latter. Feedback may conservatively require the verified cutoff even when the model omits that row; this is a submission filter, not a new model restriction.

The canonical `G` is an epigraph. A nonoptimal master candidate may have `G_model > G_true`, including `G_true` below the interval lower boundary. The physical UB is its independently evaluated true objective. Such a point does not prove a true optimum inside I.

## Proof chain

1. **Embedding.** Take any solution of O. Use its original route arcs, prefix/return loads, service, inventory selectors, order/resource variables, and original objective auxiliaries. Route relaxation admits those original values. Every original canonical row remains and every learned conflict is valid for physical routes, so the solution lies in R. Therefore a numerically/parametrically qualified native lower bound is a lower bound for this request's original domain. Empty domains satisfy the statement vacuously. A paid global witness is required to embed only if its complete mapping satisfies this domain; a leaf may legitimately have no Start.
2. **Validation or exclusion.** Retained integer service columns determine unique one-direction operations and exact Y. A/B use the unchanged conservative MST and complete six-order/strict extra-pickup proofs. FULL is native INFEASIBLE in an independent all-station optional single-car physical model. These proofs depend on full operations, Q/T/handling/travel/numeric contracts and never on Gini/cutoff. Every exclusion preserves O. UNKNOWN proves neither feasibility nor impossibility. All-car independently verified routes establish an own global physical UB. The integer objective epigraph satisfies `Ftrue <= modelObj` within the original tolerance; violation is ERROR and invalidates all new result bound/terminal bits from this request.
3. **Local result.** Reliable INFEASIBLE excludes only this request domain. INF_OR_UNBD, no incumbent and ordinary interruption do not. An actually embedded legal domain witness contradicted by INF is ERROR. A leaf bound exceeding the global UB is valid dominance, not an error. Native OPTIMAL closes only after its final accepted service mode is completely physically verified and its qualified local LB reaches the own global physical UB at the original closing tolerance. This is closure by dominance, distinct from an optimum with true G in I. Without that closing condition native OPTIMAL does not close or fabricate a target transition.
4. **Complete aggregation.** ENS alone merges qualified local bounds into their corresponding obligations and maintains every other open leaf, replacement relationship, initial zero bound and incumbent epoch. It certifies only when its original complete-cover/monotonicity/lifecycle/witness gates close the original problem. A high single-leaf LB, single-car oracle objective, candidate objective or partial-target success cannot certify the global problem. Excluded improving domains retain the feasible incumbent as a candidate for the global optimum; including that witness in aggregation is not numerical clipping of a contradictory bound.

At zero denominator the evaluator uses G=0 and retains all penalty. A zero global objective with nonnegative components permits the original nonnegative global lower bound to close. An empty strict-improvement domain may return INF without any Start even though a global witness exists. Domain boundaries remain those read from canonical rows. Tightened cutoffs inherit previously valid bounds and exclusions because the new improving domain is a subset; the original controller invalidates canonical/LP/child caches by epoch and does not erase its milestone in the same epoch.

## Evidence and feedback

Each formal run owns an isolated evidence session. Complete semantic coefficients are retained before missing-state removal. An omitted VD-P selector denotes zero only in the current canonical inventory domain, and mapping is rebuilt from current column names each request. Old column indices and cutoff-dependent conclusions never transfer. FEAS/INF/A/B proofs can transfer only with complete matching physical/numerical keys. First proof, cache hit, cross-request hit, remapping and actual lazy submission are different events. Learned rows are never added to child LPs or static matrices.

The global physical witness archive is independent of native acceptance. Feedback uses the unchanged full-column mapper with this request's actual I/effective cutoff, then objective/bounds/integrality/all base rows and proved rows are audited. Out-of-domain witnesses remain global UBs and record an explicit skipped feedback. Dedupe is per request; a fleet submitted in another domain is not assumed submitted here. API0/deferred, later exact-vector observation and final native-vector acceptance remain separate.

Only original LP requests go to the original all-continuous backend, with no event oracle or learned rows. Integer requests read a fresh canonical model; the native lazy pool is not converted into an LP. One native Optimize per original MIP request contains all events and conflicts; no candidate restart occurs. Multiple ENS requests mean multiple Optimizes, without any claim of preserved native B&B tree or basis. Source identity alone is not the proof.

## Stop and progress

All environments are separate and serial, with one pre-startup whole-run deadline. Inner calls receive its remaining time. A reliable rejection may stop checking other cars. Without a rejection, unresolved/UNKNOWN terminates the whole algorithm and clears target/closure eligibility; suspicious final bound/incumbent attributes are not used. Previously qualified local bounds and independently verified physical UB may survive. ERROR discards all newly generated local bound/terminal eligibility for that request. Deadline permits cancellation and evidence finalization but no new Optimize/IIS.

R92's conditional finite-progress proof still requires finite LP/native returns or whole-run stop. The finite depth/width tree and finite physical incumbent improvements imply finitely many epochs/leaf IDs. Same-epoch child LP identity/target caching plus the once-only frontier milestone yields a discrete transition to atomic split or the once-only terminal request; the adapter creates no new requeue. A native OPTIMAL without legitimate closure stops with an open obligation rather than breaking this proof. This establishes controller finiteness under the accepted-return assumptions, not a bound on native solving time or exact rational certification.
