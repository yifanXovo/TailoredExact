# Scope relative to existing methods

| Original source | Relevant existing idea | Scope of this round |
|---|---|---|
| Erdoğan, Battarra, Wolfler Calvo (2015), [An exact algorithm for the static rebalancing problem arising in bicycle sharing systems](https://doi.org/10.1016/j.ejor.2015.03.043), [author institution record](https://researchportal.bath.ac.uk/en/publications/an-exact-algorithm-for-the-static-rebalancing-problem-arising-in-/) | Exact branch-and-cut and combinatorial Benders feasibility reasoning for static bicycle rebalancing with multiple visits. | The present model has variable inventory targets, single nonzero directional service, empty departure and loaded return. Its rows are redundant selector-event ranks, rather than necessary lazy feasibility rows or a new Benders decomposition. |
| Erdoğan, Laporte, Wolfler Calvo (2014), [The static bicycle relocation problem with demand intervals](https://doi.org/10.1016/j.ejor.2013.12.013), [repository record](https://eprints.soton.ac.uk/367453/) | Routing with inventory demand intervals; full formulation and Benders decomposition. | Threshold lower requirements are relaxed physical conditions used to bound fleet event counts. The Gini objective and the original complete ENS frontier remain unchanged. |
| Letchford, [On upper bounds for the multiple knapsack assignment problem](https://www.lancaster.ac.uk/people/letchfoa/articles/mkap-bounds.pdf) | Assignment-aware upper bounds improve relaxations of packing separate knapsacks. | Fleet events share vehicle qualification and processing resources. Exact small subset assignment and polynomial slot relaxations are familiar bounding techniques; their BRP resource prerequisites and existing-selector projection are what this round evaluates. |
| [Gurobi C callback reference](https://docs.gurobi.com/projects/optimizer/en/current/reference/c/callback.html), [callback codes](https://docs.gurobi.com/projects/optimizer/en/current/reference/numericcodes/callbacks.html), [global validity requirement](https://support.gurobi.com/hc/en-us/articles/360013197472-Can-I-add-locally-valid-constraints-in-Gurobi-MIP) | GRBcbcut is available at MIPNODE; optimal-node relaxation reads, sparse submission, original-variable translation and PreCrush are documented. Local-only user constraints are unsupported. | Dynamic submission is an execution method. Its API success is separated from solver retention, performance, and physical/model validity. |

Generic cover/rank inequalities, Hall reasoning, knapsack covers and subset DP are not claimed as new theory. R62 already implemented service threshold cliques/projections in this repository; R88's B3 label identified an untested fleet allocation gap. Potential increment here must be supported by current complete-model or actual native-node evidence and full-method outcomes.
