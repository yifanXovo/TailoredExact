## J: exact support of a necessary single-car system

For every station retain choices (0,0,0), (a,0,1) for integer1<=a<=min(b_i,Q_k), or (0,b,1) for integer1<=b<=min(C_i-b_i,Q_k). Retain every station, including zero-weight supply/receivers. Define cumulative P,D, require final D<=P, and max_served ell_i+cP<=T. ell is a protected sum of audited shortest-path lower distances from/to depot. Any legitimate route embeds: single-service direction supplies station choices; empty departure and nonnegative return give D<=P; total handling is cP; every served station's travel lower bound is paid. Cumulative pickup can exceed Q. These are necessary conditions only; they omit full route travel, visit ordering and load prefixes.

Sort stations by ell. For each prefix, the multiple-choice DP stores maximum exact integer profit at each (P,D). A station transition chooses skip, pickup a or delivery b, adds alpha*a+gamma or beta*b+gamma, and always reads the preceding layer. It never requires D<=P in intermediate layers. Each distinct travel level queries final D<=P and the safe pickup cap for that level. Taking the maximum over every level and empty solution is a complete maximization of the declared necessary system. Prefixes are a union of outer relaxations, not a fixed tested service set. All levels are completed before any RHS is available.

Let U be the smaller of summed pickup operation caps and the safely retained time cap. P,D are monotone; a final D<=P<=U cannot have passed through D>U. Thus a square(U+1)^2 DP is safe. Complexity O(V U^2 (maxQ+1)), rolling space O(U^2), plus O(V U^2) level queries. c0 uses summed finite caps, never division. Unsupported resource dimension>2048 or score range>=2^52 returns no bound. Production treats proof failure as fatal evidence failure, never scores a silent fallback. Integer profits and maxima do not suffer objective roundoff; LLONG_MIN, multiplication/addition ranges and nonfinite resource inputs are checked before use.

For fixed weights, B_k is this exact maximum (or a safe larger value from outward resource arithmetic). Sum_k w_k v_k<=sum_k B_k follows by independent containment. Ignoring unique cross-car access can make this weak. A nonnegative multiplier mu gives sum mu+sum_k support(w_k-mu*z); the offline API supports this standard bound, but the production candidate uses mu0. Neither support functions, knapsack DP nor Lagrangian bounds are claimed as new inventions.

The C++ catalog has two uniformly specified directions: inverse-capacity weights on the larger p/A versus d/B service direction; and a fixed-charge direction using the current p/z or d/z threshold, always clamped before integer conversion. ## S redundancy scope and the retained F0 hull

A useful sufficient implication test applies to any distinct-station pickup event set: for0<=u<=U and1<=q<=U, h_q(u)<=u/U. If actual old rows establish sum_E u<=B and u<=U, maximize sum_E u/U by fractional knapsack, filling smallest U first. For mixed pickup/drop events, use the separately established pickup and drop budgets and add their two knapsack bounds; sum D<=sum P makes the same fleet budget a safe bound for both. A failed sufficient test establishes neither redundancy nor nonredundancy.

## Related primary work and contribution boundary

[Sinha and Zoltners (1979), The Multiple-Choice Knapsack Problem](https://pubsonline.informs.org/doi/abs/10.1287/opre.27.3.503?journalCode=opre) defines disjoint alternative-choice groups with a resource budget and studies LP-based branch-and-bound. The publisher abstract was accessible; the full PDF fetch timed out. Our station alternatives use that established grouping concept, with two aggregate integer quantities and the union over singleton-travel levels. We neither reproduce that paper's algorithm nor claim to invent multiple-choice optimization or DP.

[Fisher (1981), The Lagrangian Relaxation Method for Solving Integer Programming Problems](https://doi.org/10.1287/mnsc.27.1.1), read in its [2004 primary-paper reprint](https://my.ece.utah.edu/~kalla/phy_des/lagrange-relax-tutorial-fisher.pdf), sections2–3, derives bound validity from optimizing over an enlarged integer domain and decomposes dualized assignment couplings into independent knapsack problems. Reversing minimization to maximization gives the upper-bound direction needed here. J's independent-vehicle support uses the simpler uncoupled necessary domain; the proposed J-L multiplier formula would be this standard principle, not new theory. J-L was not implemented or tested in this round. The BRP-specific result is the audited embedding, actual service-projection witnesses and complete solver evidence for the finite implemented directions.

[Gurobi's C callback reference](https://docs.gurobi.com/projects/optimizer/en/current/reference/c/callback.html), GRBcbcut, permits user cuts at MIPNODE and requires them to preserve all original integer solutions. It explains PreCrush1 and warns that added cuts can slow node processing. [Its global-validity guidance](https://support.gurobi.com/hc/en-us/articles/360013197472-Can-I-add-locally-valid-constraints-in-Gurobi-MIP) excludes relying on local node assumptions. The production proof therefore uses full original domains/global contracts, with separate SHADOW comparisons for the combined registration, PreCrush and proof path. API return0 is recorded without a retention claim.
