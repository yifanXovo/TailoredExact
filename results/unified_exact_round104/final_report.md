## What the prototype establishes

This is an implementation and BRP evaluation of ordinary LP duality, with
explicit numerical and cost qualifications. For an exact optimal dual of
an old LP plus a finite valid resource pool, the nonnegative weighted sum
of the new rows preserves that pool's root objective. Keeping the exact
nonzero support, or its vehicle groups, gives the same conclusion. Old
equalities, variable bounds, objective coefficients and constant remain.
The result does not preserve the feasible set or descendant bounds. The
paid example has root value9 for ALL/aggregate, and descendant values10/9.
See `mathematical_algorithm.md` for both bound directions and the signed
global-bound conversion compensation.

The isolated C++ primitive rejects negative/nonfinite multipliers, mixed
scope, unsafe bounds/overflow and unsupported subnormal arithmetic. Its
outward intervals and compensated coefficient deletion cover the actual
native linear API threshold. Exact Fraction recomputation and native
readback passed on the real F2 pool; the first readback failure is retained.
These are valid compensated rows, not rational optimal-dual certificates.

The production candidate pays for its current canonical LP, finite resource
generation and selected-LP qualification, then emits literal ACTIVE rows
before native MIP. Its local legal-plan bank contains only its own paid
oracle outputs. Every auxiliary Optimize/DP has an ahead-of-call record.
It uses explicit complete vehicle membership, finite no-new-direction or
resource/precision UNKNOWN, and the whole-run deadline. No objective-stall,
component time/Work gate, instance dispatch or historical direction/pool
import exists. The original typed model, all-column physical Start, old
24+1/VD-P/F0/AM0.08 policies and native strategy remain. Exact old/new row
readback precedes SHA/signature adoption. There is no B&B restart/deletion.
