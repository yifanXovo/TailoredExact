# Fleet event ranks on the imported ENS-C model

An event `(i,sign,q)` requires q>=1, one distinct station per set. With original binary one-hot inventory selectors its expression is `sum(state_i_y : y<=b_i-q)` for pickup and `sum(state_i_y : y>=b_i+q)` for delivery. Unique service, binary direction and integer inventory imply that a true event is carried by exactly one vehicle and that its operation is at least q. No new event variables are needed. G is the original epigraph variable; these proofs do not use it, an incumbent, cutoff, node bounds or local fixing.

For each vehicle, empty departure and nonnegative return load imply total pickup >= total delivery. The existing exported `sum p - sum d >=0` directly supplies this premise to the imported model. The quantity required by a subset A is therefore at least `max(sum pickup thresholds, sum delivery thresholds)`. Q bounds each individual operation; it is never used as a cumulative pickup bound. Outside suppliers and receivers remain available. Loaded return is allowed.

The imported-model audit exact-matches one-hot, inventory reconstruction and balance, unique visit, binary direction/quantity links, nonzero service, depot degree/flow, station in/out flow and all MTZ connectivity rows. It checks column types and bounds. These rows imply a depot-closed elementary route through every served station; station-only cycles are ruled out by summing their MTZ rows. The audit identifies the duration row by its entire original positive arc/pickup support, rejecting ambiguity and missing/nonpositive coefficients. It reads each arc and handling coefficient, then takes the minimum across every vehicle and the parsed physical coefficients. The common horizon is at least every imported RHS and the physical T plus the unchanged Evaluator duration tolerance. Using a subset of original rows as proof premises relaxes the full model; omitted strengthening and load-prefix restrictions cannot invalidate the proof.

Nonnegative directed shortest paths on these common arc lower coefficients permit arbitrary extra visits. Each sum and multiply is rounded down with nextafter under verified IEEE binary64 round-to-nearest, gradual underflow and disabled FTZ/DAZ. A min over paths remains a lower bound. Small supports use exact Held-Karp minimum closed visits on this closure, with a max of singleton lower bounds to preserve the shared necessary conditions near rounding boundaries. They never use the cost of a constructed tour as a lower bound. Subset rejection requires a finite safe lower duration STRICTLY greater than the safe horizon; uncertain arithmetic retains the subset. Invalid contracts prevent any row submission. The zero handling case uses only eligibility/travel and never divides by zero. Near-boundary treatment is separate from the cut violation margin.

The module's isolated directed/nonmetric test does not broaden the inherited F0/ENS admissible-input assumptions. Formal campaigns retain the original coordinate-distance convention and its existing scope restrictions.

For a fixed small E, `allowed[k][mask]` contains every subset not excluded by capacity or the safe travel/handling lower bound, including empty. Every genuine assignment embeds in this necessary relaxation. `dp[k][B]` is the maximum number covered using the first k vehicles among events in B, with disjoint subsets; `dp[0][B]=0`. Enumerating every A subset B gives `dp[k][B]=max(|A|+dp[k-1][B\A])` over allowed A, including empty. The exact relaxation rank is `dp[M][E]`. The row `sum eta<=rank` follows by partitioning true events by their actual service vehicle. The full recurrence costs O(M 3^r), rolling memory can be O(2^r); certificates retain layers for replay. Visit preprocessing is O(r^2 2^r). Production small support is at most 9; the standalone proof API rejects >10 rather than truncate a maximum. These ranks do not certify route sufficiency.

For large E, each eligible vehicle has `ell=min(singleton roundtrip lower)` over its eligible events. Any nonempty assignment to that vehicle pays at least ell, even if it serves other stations. Sort the eligible pickup and delivery thresholds separately. The maximum possible count per direction is the longest prefix whose summed q is not strictly excluded by `ell+c*q>T_upper`. This tests protected sums directly rather than flooring an unprotected quotient. It gives counts r-minus and r-plus and the upper bound `min(|E|,sum_k(r-minus+r-plus))`. With c=0, all direction-eligible events remain available.

A polynomial strengthening retains each event's actual eligibility and assigns it to a vehicle/direction slot, with the certified count capacities above. A complete maximum-cardinality bipartite matching gives an upper bound on the number of true events, since every real assignment embeds in this slot system. Mixed directions can share the handling budget: we deliberately allow each direction its entire budget, a relaxation. The matching is an upper bound, not a packing heuristic lower bound. It exploits Hall deficits missed by a plain count sum; it still does not encode full routes or claim to dominate all earlier inequalities.

Candidate selection is heuristic. Uniform thresholds q=1..max Q generate positive-mass pools for each direction and every mass-ordered prefix; all these prefixes use the scalable proof. Only their dense <=9 prefix can use exact DP, after a certified singleton assignment lower-bound screen. Three mixed threshold pools retain the largest q with mass at least .5/.75/.9 per station. No time/Work/stagnation or instance-name rule is used. Search is not exact separation of the whole rank family. At most two strongly violated rows with no majority station overlap are selected per callback. This is an explicit separation-strength parameter (diagnostics can request 1..8), not a hidden time budget. A 256-entry FIFO cache only reduces repeated computation; eviction does not skip proofs. Its binding is the complete immutable numeric/model-column contract, which is regenerated per Optimize. Submitted proofs may be re-submitted when violated; successful API submission is not permanent solver retention.

All cut coefficients are 0/1 on distinct original selectors. Sorting/clipped candidate masses never certify violation. The final activity uses the submitted coefficients and RAW original-column point with downward-enclosed sums. Only a finite lower violation strictly exceeding 10 times read-back FeasibilityTol is eligible. This numerical filter does not prove the underlying inequality. The exact integer proof and imported coefficient audit do.

Only optimal MIPNODE points are read and only GRBcbcut is used. OFF keeps ENS-C parameters. SHELL sets/read-backs PreCrush and uses the native registration without separation; SHADOW adds audit, candidate/proof/violation computation, and evidence; SUBMIT additionally submits the same selection. Original continuous LP calls do not run this callback. Both terminal and legal partial-bound-target MIPs retain their original scope/control. Matrix, API, identity or evidence failures explicitly fail and invalidate bound/certificate traces; a per-row arithmetic uncertainty skips that row. The remaining call deadline includes audit/setup cost. No nested Optimize, matrix/bound mutation, lazy constraints, restart or extra native time slice is introduced.

The generic cover/assignment-rank principle, subset DP, matching/Hall relaxation and Gurobi API are established methods. This round evaluates their specific conservative resource system, existing-selector projection, support scale, imported coefficient contract and sparse execution in the actual ENS stack. Historical R62 cliques are a special pair-conflict capability; pair-compatible higher-rank deficits are a different structure. Original single-vehicle quantity rows or general cuts can nevertheless imply individual fleet rows; complete-model and native-node evidence, rather than source absence, decides actual increment.
