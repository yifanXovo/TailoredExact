# AM admission implies a conditional proof-gap contraction

This is an explanatory lemma for the existing AM rule, not a new rule, an implementation change, or a claim that the depth safeguard can already be removed. It applies to a binary split admitted by the AM score with two valid finite child LP bounds. It does not apply automatically to the separate infeasibility-contraction or native-target branches.

Let the valid parent lower bound be B, the verified feasible upper bound be U, and D = max(U-B, certificate_tolerance, 1e-12). For child bounds B_1 and B_2 define g_i = clip((B_i-B)/D, 0, 1), eta = min(g_1,g_2), mu = (g_1+g_2)/2, and S = eta*mu. These are the quantities in `evaluateC6AdaptiveMassSplitDecision` in `src/PaperExternalGiniTree.cpp`.

**Lemma.** If S >= t for some t in [0,1], then each g_i is at least r(t) = (sqrt(1+8t)-1)/2. Consequently, when U >= B, each child's nonnegative proof gap max(0,U-B_i) is at most (1-r(t))*(U-B). The same bound holds with a subsequently improved verified upper bound U' <= U.

**Proof.** Write z = max(g_1,g_2), so 0 <= eta <= z <= 1. Then S = eta*(eta+z)/2 <= eta*(eta+1)/2. The latter expression is increasing for eta >= 0; inversion gives eta >= r(t). For t > 0, clipping implies B_i-B >= r(t)*D >= r(t)*(U-B). Rearranging and taking the nonnegative gap proves the claim. For t=0 the gap statement additionally needs B_i >= B; nested exact child relaxations have this property, and the implementation's strict child-improvement check supplies it for the AM admission branch. Decreasing U cannot increase the left side. The gain bound is sharp as an abstract statement about clipped gains: eta=r(t), z=1 attains equality in the score inequality.

With an exact score threshold tau=0.08, r(tau) is approximately 0.1403124: every such immediate binary AM adoption removes at least 14.03% of the current proof gap in both child LP bounds. This is a guarantee about admitted bounds, not about the probability of admission, total runtime, the cost of obtaining the bounds, or a speedup over P-GRB. If every step on a path satisfied the same positive t, the nonnegative proof gap after k such steps would be at most (1-r(t))^k times its starting gap, assuming valid nonincreasing incumbents.

**Numerical and scope limits.** The code actually accepts S + adaptive_score_tolerance >= tau. Its per-decision bound therefore uses t = max(0,tau-adaptive_score_tolerance), with that decision's recorded tolerance, rather than silently using 0.08. The tolerance depends on the bound scale and D and may make this lower bound uninformative near closure. Do not quote the 14.03% value as an unconditional guarantee of every floating-point acceptance. An analysis using true mathematical LP optima must also respect the project's numerical certificate conventions; solver floating-point bounds are not exact rational proofs.

The rule for a child certified infeasible can contract to the other child without passing this score; native-target outcomes follow their own evidence transitions. Arbitrarily unbalanced LP-G geometry has no midpoint width-halving guarantee. Thus this lemma alone proves neither a finite depth bound for the complete controller nor termination after removing depth 8. Round90 deliberately keeps depth 8 and the minimum width. The lemma adds a quantitative interpretation to the existing AM parameter without adding another tunable parameter or changing any candidate.
