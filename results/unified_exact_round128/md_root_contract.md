# MD-R: inclusive-root control, version 1

Frozen M-B / GI-TBC remains the only proposed paper algorithm. MD-R is an explicitly selected, off-by-default research control. Round127 remains PARTIAL: its three original MD positions were never started and are not retroactively completed by these revised observations.

For an actual interval I=[a,b] and cutoff c, suppose the verified domain reasoning establishes F(x)>=L_a=a+lambda*P_lower for every physical x in I with F(x)<=c. The remaining cutoff complement has F(x)>c. Their coverage therefore gives the valid regional bound B_I=min(L_a,c). This minimum is a consequence of two actual domains, rather than a numerical clamp on a contradictory bound. A verified witness contradicting a bound on its own domain still requires investigation under the inherited consistency policy.

At L_a>c the inclusive cutoff domain is empty, subject first to checking the premises if a valid equal-c root witness is already known. At L_a=c only strict improvement is excluded: an equal-c physical solution can remain feasible. For c-1e-9<=L_a<c, the directly justified lower bound remains L_a, not exact c; the old numerical closure does not prove absence of arbitrarily small improvement.

The V2/M1 empty-stock boundary uses Q=1, D=w=(1,1), pickup=drop=60 seconds and physical T=60. No service is possible, so Y=0, G=0, P=2 and F=U0=3/10. The old named `interval_no_improver_domain_closure` emits the impossible row 0<=-1 at equality. It excludes the legal empty fleet and cannot be treated as an inequality valid for every F<=U0 physical solution. This counterexample refutes the former MD inclusive embedding claim; it does not alone revoke every historical M-B numerical certificate. The finite saved-call impact check is limited to the three R127 core MB roles and their actual model hashes.

MD-R keeps all valid root domains, objective and cutoff rows, R/C_R/C_G, P>=P_lower, inventory/state bounds, physical constraints and original tolerances. Both the shared factory and fallback writer guard only the semantically named proof shortcut. Other constant rows, genuine domain infeasibility, the entire penalty-LB option and Gurobi's native Cutoff parameter are unchanged. No row number is used for deletion.

Every arm independently pays the unchanged complete H. The inherited startup-zero range is preserved and reported as unexposed interval control. Otherwise the fixed root is [0,min(U0,(n-1)/n)] and F_model<=U0, with the inherited n=1 convention. No historical UB or fleet enters a formal arm. In exact arithmetic, every physical F<=U0 solution has G<=F<=U0 and G<=(n-1)/n, so it lies in the root; the cutoff complement cannot improve that same-run witness. The original valid-row embedding applies after the pseudo-infeasibility shortcut is omitted.

Before root LP relaxation, MD-R maps its own complete U0 fleet against the actual native integer column types, bounds, every linear row and the original objective, using the unchanged mapper and 1e-7 evidence checks. Its read-only pre-LP vector and phase are retained. After one complete root LP, original VTypes are restored and one complete root MIP receives that same legal Start, with native Start readback. A numerical leaf-relevance tolerance cannot waive this nonzero two-call obligation. Certification also requires that complete chain and exactly one submitted Start. There are no child LPs, external targets, NEXT/AM, splits, root shrinkage, incumbent epochs or restarts. Native internal cuts and incumbents operate normally.

All work shares one complete deadline, including pre-LP validation, H, model generation, MIP Start checks and output. Backend preparation time is subtracted from the MD-R LP native allowance as well as the MIP allowance. Native infeasibility despite the validated own witness is a consistency fault. Time-limited and interrupted native returns retain their actual status and scoped bounds; they are not silently renamed native optimality. No new analytic certificate or threshold-as-bound is introduced. Raw qualified bounds and signed gaps remain visible under the inherited physical/source/return/coverage policy. These finite floating-point checks are not a global rational error bound.

A pure outer-control interpretation requires identical complete H actions/fleet, initial U0, root interval and every other actual root row/column/type/bound/objective/parameter. If ordinary MB emits the shortcut or uses a different initial scope, its comparison with MD-R is only a complete-method comparison with an explicit preprocessing difference. Absence of actual splits limits attribution to exposed probing, target handoff and scheduling; it does not demonstrate multi-leaf decomposition speedup.

Gurobi's [13.0 status reference](https://docs.gurobi.com/projects/optimizer/en/13.0/reference/numericcodes/statuscodes.html) defines OPTIMAL subject to tolerances and INFEASIBLE for the submitted model. Native CUTOFF concerns the native [Cutoff parameter](https://docs.gurobi.com/projects/optimizer/en/13.0/reference/parameters.html#parameter:Cutoff); it is distinct from the project's linear cutoff row and its proof shortcut. The local C API version and unchanged parameter readbacks are retained with the E2 qualification.
